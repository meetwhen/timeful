## Important Decisions

- Stalwart only receives; DNS SPF/DKIM stay with the relay; VM never sends.
- Caddy owns 443/ACME; wizard "automatic TLS" is disabled; Stalwart imports Caddy's cert for SMTP STARTTLS (25) and IMAPS (993).
- Manual DNS management (provider has no API).
- IMAP (993) with regular client chosen for reading mail.
- Container 8080 bound to VM loopback only; Caddy proxied HTTP via `STALWART_PUBLIC_URL=https://mail.timeful.fun`.

## Decision Rationale

- Caddy already owns port 443+TLS; Stalwart's ACME TLS-ALPN-01 would conflict, so certs are copied from Caddy's data dir and reloaded via the documented `ReloadTlsCertificates` action.
- Pin `v0.16` per official Docker docs guidance; current tag per Docker Hub `v0.16` (v0.16.18).
- Named volumes/machine-readable env like existing repo compose conventions (`${VAR:?}`).
