## Decision Rationale

- Headless setup is needed because there is no GUI/browser on the VM host and the prior runbook assumed interactive wizard answers. The docs explicitly support CLI-driven Bootstrap updates and non-interactive/declarative setup (`docs/configuration/declarative-deployments.md`).
- `CADDY_DATA_DIR` must be the Caddy volume mountpoint `/var/lib/docker/volumes/timeful-edge_caddy_data/_data` because on this VM Caddy runs as a container and stores its TLS store there; `sync-certs.sh` reads `${CADDY_DATA_DIR}/certificates/acme-v02.api.letsencrypt.org-directory/${MAIL_DOMAIN}/{crt,key}`.
- `generateDkimKeys` stays disabled because outbound is exclusively the relay's; the VM never sends.
