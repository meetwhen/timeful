## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a Firefox end-to-end spec that verifies the calendar integration lifecycle against the PostgreSQL store in the isolated test stack.

Cover connect, token refresh, sub-calendar toggle, and remove. Assert each mutation against the PostgreSQL calendar_accounts, calendar_account_credentials, calendar_sub_calendars, and calendar_preferences rows, and assert the retained MongoDB users document is never used as a second authority.

Run under the existing Playwright Firefox project with the isolated test stack and mock provider from TASK-0199.07.02. No live provider network calls are permitted.
