## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Replace mongo-driver types in the surviving PostgreSQL runtime with canonical types while preserving the current JSON wire format.

Convert server/models (Event, Response, User, CalendarEvent, SignUpBlock, SignUpResponse) and every live PostgreSQL path off primitive.ObjectID, primitive.DateTime, bson.M, and bson.A: server/routes/postgres_event_routes.go, server/routes/postgres_group.go, server/routes/event_timed_slots.go, server/routes/user.go, server/routes/folders.go, server/routes/guest_response_ownership.go, server/accounts, server/respondents, server/services/auth, server/services/calendar, server/services/listmonk, server/services/services.go, server/services/gcloud, server/slackbot, and server/discord_bot.
Delete Mongo-only models that no longer have runtime readers (Attendee, Folder, FolderEvent, EventResponse) and any dead deduction helpers.
Preserve the wire contract deliberately: 24-hex account and event identifiers, the zero-ObjectID guest sentinel surfaced to clients, RFC3339 datetime strings, millisecond-keyed manual availability maps, and the models.Event.MarshalJSON behavior, with regression tests for each.
Keep the account external-ID 24-hex format through a non-driver generator and keep the guest-name ObjectID-like validation.
Regenerate Swagger with the repo command and run npm run gen:api so server/docs and frontend/src/types/api.ts match.
<!-- SECTION:DESCRIPTION:END -->
