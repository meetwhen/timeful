## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The Go boundary currently mints a 24-hex value on sign-in (models.NewID().Hex()) and passes it through platform_identities.external_user_id; the sign-in session and models.User.Id carry it. Change the runtime so the platform identity UUID (platform_identities.id, generated by the uuidv7() default) is the account identifier: FindOrCreatePlatformIdentity no longer accepts or stores an external id, session userId stores the uuid, account resolution and ownership checks key on platform_identity_id, and models.ID no longer represents account identity. Guest and unowned zero semantics must survive the change. Swagger and the generated frontend API types are regenerated. This subtask ships together with the schema consolidation subtask; no request path may accept the legacy 24-hex account id.

Constraints:
- No compatibility lookup: after the cutover, an old 24-hex session value resolves to no account.
- Keep boundary and transport types separate from internal types per the frontend ADRs; keep transport decoding at explicit boundaries.
- Preserve the existing guest and unowned zero-identity behavior and the event and signup wire fields unrelated to account identity.
- Follow the backend conventions in AGENTS.md, including Swagger regeneration (swag v1.16.6) and npm run gen:api.
<!-- SECTION:DESCRIPTION:END -->
