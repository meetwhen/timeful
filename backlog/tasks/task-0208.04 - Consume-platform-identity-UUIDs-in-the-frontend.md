## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Frontend boundary types and views still treat account and user identifiers as 24-hex ObjectID-style strings. After the backend cutover, account identity is the platform identity UUID. Update transport decoding and boundary types, remove ObjectID-based assumptions (Dashboard event sorting and signup block local _id generation currently use bson-objectid), and keep one canonical internal shape per concept. Coordinate with TASK-0177.01 so its bson-objectid removal is consistent with this change. Depends on the ADR; integrates after the backend and schema subtasks.

Constraints:
- Keep compatibility coercions and transport decoding at explicit boundaries per the frontend ADRs; do not coerce in views or composables.
- Preserve visible ordering and identity behavior unless the current behavior is proven dead; add unit coverage for any behavior change.
- Follow frontend/AGENTS.md.
<!-- SECTION:DESCRIPTION:END -->
