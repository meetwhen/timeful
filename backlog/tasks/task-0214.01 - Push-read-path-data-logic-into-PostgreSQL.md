# Goal

Push read-path data logic that currently loops in Go into set-based PostgreSQL queries.

# Scope

- `server/routes/analytics.go:137-154` and `:224-237`: replace the per-day `CountDistinctMonthlyActiveEventCreators*` loop with one query over an `unnest`/`generate_series` reporting table; preserve ascending day order and the existing error-handling decision.
- `server/postgres/dailylogs.go:133-160`: replace `padDailyUserLogs` slice splicing with `generate_series($1::date, $2::date, '1 day') LEFT JOIN daily_user_logs`; preserve newest-first order, empty member slices, and today inclusivity.
- `server/routes/postgres_event_routes.go:279-291`: batch response authorization so `visitor.controls` does not run one EXISTS per response; preserve blind-availability filtering and controls precedence.
- `server/routes/respondent_identity.go:55-88`: join `accounts` into `ListSignupResponses` instead of one lookup per response; preserve the deleted-account fallback and sanitization.
- `server/routes/postgres_group.go:129-153` and `:81-95`: replace the full response scan and EqualFold attendee loop with EXISTS predicates on indexed columns.
- `server/postgres/calendar.go:113-134`: drop or consolidate `requirePlatformIdentityID` and `calendarAccountID` pre-queries where a merged statement is equivalent; preserve `pgx.ErrNoRows` behavior.
- `server/postgres/transfers.go:78-84`: fetch the transfer source credential in one query.

# Constraints

- SQL stays in `server/postgres/`; routes must not access PostgreSQL directly.
- Preserve wire shapes, ordering, and authorization semantics exactly.
- No schema changes in this subtask.

# Verification

- Run the backend suite with the isolated test overlay in `compose.test.yaml`.
- Add or update repository and route tests for each changed path before or with the fix.
