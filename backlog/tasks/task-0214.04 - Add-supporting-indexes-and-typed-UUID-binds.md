## Description

# Goal

Add the indexes that existing query shapes need and stop defeating indexes with UUID-to-text casts.

# Scope

- Add a goose migration in `server/migrations/` for:
  - `postgres_event_responses (event_id, created_at, id)`.
  - `event_attendees` predicates and ordering, including `lower(email)`.
  - `postgres_events (created_at)` including `creator_posthog_id` for analytics windows.
  - `daily_user_log_members (daily_user_log_id, first_seen_position)`.
- Replace `::text` casts on UUID columns with typed UUID binds or validated values in `server/postgres/signup.go:131,254,335,355,384`, `server/postgres/identities.go:58,87`, `server/postgres/transfers.go:35`, and `server/postgres/accounts.go:263`.
- Validate opaque client identifiers with `models.ParseUUID` at the boundary and return `pgx.ErrNoRows` for non-canonical values.

# Constraints

- The baseline migration is immutable; add a new migration instead.
- Preserve not-found behavior for non-canonical IDs; do not surface `22P02` errors to routes.
- SQL stays in `server/postgres/`.

# Verification

- Use `EXPLAIN` against the isolated test database to confirm index usage.
- Run the route and repository test suites under `compose.test.yaml`.
