## Description

# Goal

Add the indexes that existing query shapes need and stop defeating indexes with UUID-to-text casts.

# Scope

- Add a goose migration in `server/migrations/` for:
  - `postgres_event_responses (event_id, created_at, id)`.
  - `event_attendees` predicates and ordering, including `lower(email)`.
  - `postgres_events (created_at)` including `creator_posthog_id` for analytics windows.
  - `daily_user_log_members (daily_user_log_id, first_seen_position)`.
- After TASK-0214.03 lands, replace the remaining `::text` casts on UUID columns with typed UUID binds or validated values in `server/postgres/identities.go:58,87`, `server/postgres/transfers.go:35`, and `server/postgres/accounts.go:263`, plus the `public_id` lookups in `server/postgres/signup.go`; re-locate that task's signup.go block-membership references against the post-TASK-0214.03 file.
- Validate opaque client identifiers with `models.ParseUUID` at the boundary. Non-canonical identifiers keep their current mapping: `pgx.ErrNoRows` (404) for event, response, and transfer identifiers, and `ErrSignupBlockNotFound` (400 `signup-block-not-found`) for signup block identifiers.

# Constraints

- The baseline migration is immutable; add a new migration instead.
- Preserve not-found behavior for non-canonical IDs; do not surface `22P02` errors to routes.
- Do not map non-canonical signup block identifiers to `pgx.ErrNoRows`; their contract is `ErrSignupBlockNotFound`.
- SQL stays in `server/postgres/`.

# Verification

- Use `EXPLAIN` against the isolated test database to confirm index usage.
- Run the route and repository test suites under `compose.test.yaml`.
- Confirm signup block identifier errors still map to `signup-block-not-found` after the typed binds.
