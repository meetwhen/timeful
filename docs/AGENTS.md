# Documentation Authoring

These instructions apply to Markdown documentation under `docs/`.

- Write each Markdown sentence on one physical source line, and never split a sentence across lines.
- Keep each Markdown table row on one physical source line, even when its cells contain multiple sentences.
- Before authoring or changing prose that refers to controlled terms, read `terminology/README.md`.
- Use controlled terms exactly as `terminology/glossary.md` records them, and follow `terminology/README.md` for canonicalization and linking rules.
