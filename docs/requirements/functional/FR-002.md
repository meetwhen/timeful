# FR-002: Project Timed Slots Into Their Display-Date Columns

The timed grid shall render a column for every civil date in the selected display timezone to which at least one timed slot projects.

Each timed-grid column shall contain only slots whose instants project to that column's civil date. This includes an adjacent date when a slot projects across midnight.
