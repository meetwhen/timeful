# FR-009: Present Timed-Grid States Consistently

Timed grids shall identify a cell's state with context-specific labels and visually distinct states.

## Acceptance Criteria

- In the specific-times editor, selected event slots are white, selectable event slots are light grey, and cells outside the event-date domain are dark grey.
- In an event availability grid, an active slot unavailable to the current respondent is pale red and is labeled `Unavailable, change in Add/Edit availability`.
- The legend shows only states that can occur in the current mode and does not expose internal enabled, inactive, or domain terminology.
- Enabled inactive cells remain editable where the editing mode allows them; dark-grey padding cells are non-editable.
- Padding occurs only in cells without an enabled slot for that display-date column and is not created by page-wide filler rows.
