# FR-010: Define The Specific-Times Editor Domain From Picked Dates

The specific-times editor shall make every increment from 00:00 inclusive through the next 00:00 exclusive available for each date picked in the event timezone.

## Acceptance Criteria

- The editor shows every picked date even when it has no active slots.
