# FR-012: Maintain A Single Timeful Schedule

Anyone with an event link shall be able to save one selected time range as that event's Timeful schedule.

## Acceptance Criteria

- Rescheduling replaces the existing Timeful schedule.
- Clearing the Timeful schedule removes the saved range.
- The saved schedule remains visible while availability remains visible behind it.
- The Schedule menu lists Timeful first, followed by Google Calendar and Outlook; the mobile Schedule action offers the same destinations.
- After saving a Timeful schedule, the event page offers Reschedule event and Clear actions.
