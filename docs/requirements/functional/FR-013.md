# FR-013: Preserve Timed-Slot Instants Across Display-Timezone Changes

Changing the display timezone shall preserve every timed slot's instant and shall not change the event timezone.

## Acceptance Criteria

- A slot's projected date, clock label, tooltip date and time, and grid column update for the selected display timezone.
- A slot renders no more than once, including when its displayed time crosses midnight.
- Wrapped ranges remain continuous without structural split gaps.
