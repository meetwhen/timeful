# FR-014: Derive Timed-Grid Cell States From Event Domains

Timed grids shall derive active, enabled-inactive, and disabled-padding cells from active slots and the event date domain.

## Acceptance Criteria

- In the specific-times editor, active slots are selected, enabled inactive slots remain editable, and cells outside the enabled domain are non-editable padding.
- On a specific-times event page, the grid axis uses the saved active-range band, falling back to the enabled domain. The full civil-day axis appears only in the editor or when Show all hours is enabled.
- On a specific-times event page, active slots are respondent-selectable and enabled inactive slots are not respondent-selectable.
- Range-event grids render the selected range with hour-aligned axis boundaries.
- Enabled-inactive cells are light grey, and padding outside the event-date domain is dark grey.
