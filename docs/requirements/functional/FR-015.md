# FR-015: Save Active Custom-Domain Slots Only Within The Enabled Domain

When a [Custom Domain Mode](../../terminology/glossary.md#custom-domain-mode) event is saved, the system shall discard each [Active Slot](../../terminology/glossary.md#active-slots) outside that event's [Enabled Slots](../../terminology/glossary.md#enabled-slots).
