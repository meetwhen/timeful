# FR-016: Limit Scheduling To Active Slots

On a timed event page while scheduling or rescheduling an event, the system
shall allow a schedule drag to start and end only on active slots.

When a drag moves into an enabled inactive slot, the schedule selection shall retain its last active endpoint.
