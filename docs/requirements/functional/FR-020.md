# FR-020: Keep The Mobile Selected-Slot Tooltip Available After Scrolling

On a mobile event page, a selected timeslot shall remain selected while the user scrolls.

When that selected timeslot is visible in the grid, its time-and-date tooltip shall be visible adjacent to it. No tooltip shall be visible when no timeslot is selected.
