# FR-024: Keep Event And Display Time Formats Independent

The event time format shall control times in event editor forms, and the display time format shall control times in event-page grids and tooltips.

Changing either format shall not change the other format.

## Acceptance Criteria

- The event time format persists as an event-editor preference.
- The display time format persists as an event-page preference and applies across event pages.
