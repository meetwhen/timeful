# FR-041: Cue Availability Editing From Unavailable Timed-Grid Areas

When a viewer selects an unavailable area of a [Timed Event](../../terminology/glossary.md#timed-event) grid in read mode,
the applicable Add availability or Edit availability action shall blink.
