# FR-045: Show Event Guests As Unavailable For Unavailable Timed-Grid States

When the user hovers a pale-red, light-grey, or dark-grey unavailable timed-grid state, the Responses view shall show every [Event Guest](../../terminology/glossary.md#event-guest) as unavailable.
