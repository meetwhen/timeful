# FR-050: Activate Range Slots For Newly Picked Dates

When an event using a within-date time range gains a [picked date](../../terminology/glossary.md#picked-dates), the system shall activate every increment whose start is within the configured range in the event timezone.

## Acceptance Criteria

- The start is inclusive and the end is exclusive. For a 15-minute `09:00–17:00` range, slots beginning at `09:00` through `16:45` are active.
- A range does not cross midnight in the event timezone.
