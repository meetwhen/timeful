# FR-051: Keep Newly Picked Specific-Times Dates Inactive

When a specific-times event gains a [picked date](../../terminology/glossary.md#picked-dates), the system shall add that date's full [enabled-slot](../../terminology/glossary.md#enabled-slots) domain without activating slots.
