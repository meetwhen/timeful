# FR-051: Keep Newly Picked Custom Domain Mode Dates Inactive

When an event in [Custom Domain Mode](../../terminology/glossary.md#custom-domain-mode) gains a [Picked Date](../../terminology/glossary.md#picked-dates), the system shall add that date's full [Enabled Slots](../../terminology/glossary.md#enabled-slots) domain without activating slots.
