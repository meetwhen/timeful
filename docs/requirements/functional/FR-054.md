# FR-054: Convert Specific-Times Events To Range Events

An event creator shall be able to convert a specific-times event to a range event. The creator's selected range, interpreted in the [event timezone](../../terminology/glossary.md#event-timezone), shall replace the manually selected [active slots](../../terminology/glossary.md#active-slots) for every picked date.
