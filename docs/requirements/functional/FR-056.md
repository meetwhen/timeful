# FR-056: Preserve Timed-Event State On No-Op Saves

Saving an unchanged timed event shall preserve its [picked dates](../../terminology/glossary.md#picked-dates), [active slots](../../terminology/glossary.md#active-slots), [event timezone](../../terminology/glossary.md#event-timezone), and slot-generation settings.
