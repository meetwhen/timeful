# FR-057: Apply Timed-Event Timezone Transition Rules

When a timed event's [event timezone](../../terminology/glossary.md#event-timezone) changes, the system shall keep picked dates stable unless doing so would remove cross-midnight [active slots](../../terminology/glossary.md#active-slots). In that case, it shall re-anchor picked dates to the active slots' local dates in the new event timezone; it shall discard any remaining active slot outside the rebuilt enabled domain.
