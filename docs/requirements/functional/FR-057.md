# FR-057: Apply Timed-Event Timezone Transition Rules

When a [Timed Event](../../terminology/glossary.md#timed-event)'s [Event Timezone](../../terminology/glossary.md#event-timezone) changes, the system shall keep [Picked Dates](../../terminology/glossary.md#picked-dates) stable unless doing so would remove cross-midnight [Active Slots](../../terminology/glossary.md#active-slots). In that case, it shall re-anchor picked dates to the active slots' local dates in the new Event Timezone; it shall discard any remaining active slot outside the rebuilt [Enabled Slots](../../terminology/glossary.md#enabled-slots) domain.

The system shall discard each timed availability-response slot that is not active in the rebuilt domain. It shall not re-anchor availability-response slots.
