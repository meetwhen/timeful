# FR-059: Validate And Normalize Respondent Names

Before creating or updating a response, the system shall remove control and Unicode-format characters, trim whitespace, and normalize the respondent name to NFC.

## Acceptance Criteria

- The normalized name must be non-empty and no more than 100 code points.
- The system shall reject ObjectID-like names.
- Respondent names compare case-sensitively after normalization.
- A respondent identity may have only one response per event; duplicate display names are not allowed.
