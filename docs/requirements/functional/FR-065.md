# FR-065: Show Availability Responses For Availability Editing

When a visitor opens availability editing, the system shall list every [Availability Response](../../terminology/glossary.md#availability-response), including [Protected Responses](../../terminology/glossary.md#protected-response) the visitor cannot edit. It shall permit editing only for availability responses the visitor is authorized to edit.

## Acceptance Criteria

- Before the visitor selects an availability-response subset, the list orders availability responses owned by the visitor's [Event Guest](../../terminology/glossary.md#event-guest) first, then other [Open Responses](../../terminology/glossary.md#open-response), then other [Protected Responses](../../terminology/glossary.md#protected-response).
