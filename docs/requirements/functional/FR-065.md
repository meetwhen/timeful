# FR-065: Show Responses For Availability Editing

When a visitor opens availability editing, the system shall list every response, including [protected responses](../../terminology/glossary.md#protected-response) the visitor cannot edit. It shall permit editing only for responses the visitor is authorized to edit.

## Acceptance Criteria

- Before the visitor selects a response subset, the list orders the visitor's responses first, then other [open responses](../../terminology/glossary.md#open-response), then other protected responses.
