# FR-066: Filter The Availability-Editor Grid By Response Selection

In availability editing, a visitor may select responses regardless of whether they are authorized to edit them. When one or more responses are selected, the grid shall show availability and calculate overlaps only for the selected responses.

## Acceptance Criteria

- Initially, the grid shows every response's availability and no response checkbox is selected.
- Selecting a response moves it before unselected responses while preserving the prior relative order within the selected and unselected groups.
- Changing the selection shall not change which responses the visitor is authorized to edit.
- Clearing the final selected response restores every response's availability and overlap calculation.
- Reloading the page restores the initial selection state.
