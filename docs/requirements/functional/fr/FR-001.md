# FR-001: Preserve Event Guest Availability Responses

An [Event Guest](../../../terminology/glossary.md#event-guest) can create and own multiple [Availability Responses](../../../terminology/glossary.md#availability-response) for an event through the guest's [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity).

The system shall retain each [Availability Response](../../../terminology/glossary.md#availability-response) with its creating [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) as its owner, independently of the response's display name.
It shall not use a raw [Platform Identity](../../../terminology/glossary.md#platform-identity) value as the response identifier or owner.
