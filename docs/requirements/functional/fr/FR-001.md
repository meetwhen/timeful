# FR-001: Preserve Event Guest Availability Responses

An [Event Guest](../../../terminology/glossary.md#event-guest) can own multiple [Availability Responses](../../../terminology/glossary.md#availability-response) for an event.

The browser shall retain each [Availability Response](../../../terminology/glossary.md#availability-response) owned by the [Event Guest](../../../terminology/glossary.md#event-guest).
