# FR-001: Preserve Event Guest Event Responses

An [Event Guest](../../../terminology/glossary.md#event-guest) can create and own multiple [Event Responses](../../../terminology/glossary.md#event-response) for an event through the guest's [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity).

The system shall retain each [Event Response](../../../terminology/glossary.md#event-response) with its creating [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) as its owner, independently of the response's display name.
It shall not use a raw [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity) value as the response identifier or owner.
