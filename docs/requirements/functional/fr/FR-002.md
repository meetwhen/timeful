# FR-002: Project Timed Slots Into Their Projected Date Columns

The [Timed Grid](../../../terminology/glossary.md#timed-grid) shall render a [Projected Date Column](../../../terminology/glossary.md#projected-date-column) for every [Civil Date](../../../terminology/glossary.md#civil-date) in the selected [Display Timezone](../../../terminology/glossary.md#display-timezone) to which at least one [Timed Slot](../../../terminology/glossary.md#timed-slot) projects.

Each [Projected Date Column](../../../terminology/glossary.md#projected-date-column) shall contain only [Timed Slots](../../../terminology/glossary.md#timed-slot) whose [Instants](../../../terminology/glossary.md#instant) project to that column's [Civil Date](../../../terminology/glossary.md#civil-date).
This includes an adjacent date when a slot projects across midnight.
