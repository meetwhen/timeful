# FR-004: Require a Non-Empty Availability Response

The system shall permit saving an [Availability Response](../../../terminology/glossary.md#availability-response) only when it contains at least one [Available](../../../terminology/glossary.md#available) or [If needed](../../../terminology/glossary.md#if-needed) slot.
