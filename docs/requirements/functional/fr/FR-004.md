# FR-004: Require a Non-Empty Event Response

The system shall permit saving an [Event Response](../../../terminology/glossary.md#event-response) only when it contains at least one [Available](../../../terminology/glossary.md#available) or [If needed](../../../terminology/glossary.md#if-needed) slot.
