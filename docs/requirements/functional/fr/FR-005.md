# FR-005: Render The Edited Availability Response As An Overlay Above Other Availability Responses

When the [Availability Response Overlay](../../../terminology/glossary.md#availability-response-overlay) is enabled in the [Availability Editor](../../../terminology/glossary.md#availability-editor), the grid shall render the edited [Availability Response](../../../terminology/glossary.md#availability-response) as an elevated overlay above other Availability Responses.
