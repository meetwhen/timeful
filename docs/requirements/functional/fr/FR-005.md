# FR-005: Render The Edited Event Response Elevated Above Other Event Responses

When the [Event Response Overlay](../../../terminology/glossary.md#event-response-overlay) is enabled on a response editing page, the grid shall render the edited [Event Response](../../../terminology/glossary.md#event-response) as an elevated overlay above other **Event Responses**.
