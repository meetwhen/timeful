# FR-005: Layer The Edited Availability Response Above Availability Overlays

When [Availability Overlays](../../../terminology/glossary.md#availability-overlay)
are enabled in the [Availability Editor](../../../terminology/glossary.md#availability-editor),
the grid shall render the edited [Availability Response](../../../terminology/glossary.md#availability-response)
visually above all overlays.
