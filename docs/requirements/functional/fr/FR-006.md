# FR-006: Keep Availability Statuses Mutually Exclusive

For each [Event Response](../../../terminology/glossary.md#event-response) slot, the [Availability Status](../../../terminology/glossary.md#availability-status) shall be exactly one of [Available](../../../terminology/glossary.md#available), [If needed](../../../terminology/glossary.md#if-needed), or [Unavailable](../../../terminology/glossary.md#unavailable).
