# FR-006: Keep Availability States Mutually Exclusive

For each [Availability Response](../../../terminology/glossary.md#availability-response) slot, the [Availability State](../../../terminology/glossary.md#availability-state) shall be exactly one of [Available](../../../terminology/glossary.md#available), [If needed](../../../terminology/glossary.md#if-needed), or [Unavailable](../../../terminology/glossary.md#unavailable).
