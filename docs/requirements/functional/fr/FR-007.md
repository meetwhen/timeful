# FR-007: Hide Platform Sign-In Entry Points When Platform Sign-In Is Disabled

When [Platform Sign-In](../../../terminology/glossary.md#platform-sign-in) is disabled, the frontend shall gate all functionality related to **Platform Sign-In**, including sign-in and sign-up entry points and routes.
