# FR-008: Initialize The Ranged Domain Mode Active Slot Range

A new [Timed Event](../../../terminology/glossary.md#timed-event) in [Ranged Domain Mode](../../../terminology/glossary.md#ranged-domain-mode) shall initialize its [Active Slot Range](../../../terminology/glossary.md#active-slot-range) to 09:00 through 18:00 in the [Event Timezone](../../../terminology/glossary.md#event-timezone).
