# FR-009: Present Timed Grid States Consistently

[Timed Grids](../../../terminology/glossary.md#timed-grid) shall identify a
cell's state with context-specific labels and visually distinct states.

## Acceptance Criteria

- In [Custom Domain Editing](../../../terminology/glossary.md#custom-domain-editing), selected [Active Slots](../../../terminology/glossary.md#active-slots) are white, selectable [Enabled Inactive Slots](../../../terminology/glossary.md#enabled-inactive-slot) are light grey, and cells outside the [Enabled Slots](../../../terminology/glossary.md#enabled-slots) domain are dark grey.
- In an event availability grid, an [Active Slot](../../../terminology/glossary.md#active-slots) unavailable to the current respondent is pale red and is labeled `Unavailable, change in Add/Edit availability`.
- The legend shows only states that can occur in the current mode and does not expose internal [Enabled Slots](../../../terminology/glossary.md#enabled-slots), inactive, or domain terminology.
- [Enabled Inactive Slots](../../../terminology/glossary.md#enabled-inactive-slot) remain editable where the editing mode allows them; dark-grey [Disabled Padding Cells](../../../terminology/glossary.md#disabled-padding-cell) are non-editable.
- Padding occurs only in cells without an [Enabled Slot](../../../terminology/glossary.md#enabled-slots) for that [Projected Date Column](../../../terminology/glossary.md#projected-date-column) and is not created by page-wide filler rows.
