# FR-010: Support Custom Domain Editing

[Custom Domain Editing](../../../terminology/glossary.md#custom-domain-editing) shall make every [Timed Slot](../../../terminology/glossary.md#timed-slot) at the configured [Slot Increment](../../../terminology/glossary.md#slot-increment) from 00:00 inclusive through the next 00:00 exclusive available for each [Picked Date](../../../terminology/glossary.md#picked-dates) in the [Event Timezone](../../../terminology/glossary.md#event-timezone).

## Acceptance Criteria

- The editor shows every [Picked Date](../../../terminology/glossary.md#picked-dates) even when it has no [Active Slots](../../../terminology/glossary.md#active-slots).
