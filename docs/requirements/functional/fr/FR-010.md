# FR-010: Support Custom Timed Domain Editing

[Custom Timed Domain Editing](../../../terminology/glossary.md#custom-timed-domain-editing) shall make every [Time Slot](../../../terminology/glossary.md#time-slot) of the configured [Slot Duration](../../../terminology/glossary.md#slot-duration) from 00:00 inclusive through the next 00:00 exclusive available for each [Event Picked Date](../../../terminology/glossary.md#event-picked-dates) in the [Event Timezone](../../../terminology/glossary.md#event-timezone).

## Acceptance Criteria

- The editor shows every [Event Picked Date](../../../terminology/glossary.md#event-picked-dates) even when it has no [Active Slots](../../../terminology/glossary.md#active-slots).
