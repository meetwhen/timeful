# FR-011: Collapse Inactive Timed Grid Runs

On a [Timed Event](../../../terminology/glossary.md#timed-event) page while viewing or scheduling an event, when the ["Collapse disabled times" Option](../../../terminology/glossary.md#collapse-disabled-times-option) is enabled, the grid shall collapse leading, interior, and trailing inactive runs of at least three consecutive whole hours.

The option switch shall read on only while every collapsible run is collapsed across all grid pages, turning off when any collapse band is manually expanded.
Turning the switch on shall collapse every collapsible run on every grid page.

This requirement does not apply during [Availability Editing](../../../terminology/glossary.md#availability-editing) or on the [Timed Event Scheduling Page](../../../terminology/glossary.md#timed-event-scheduling-page).

## Acceptance Criteria

- Collapse bands align to complete hours.
- The time axis shows each collapsed band's start boundary, including a day boundary such as 00:00 when applicable.
- Scheduling does not expand collapsed bands.
- Calendar, selected, and saved occurrence-span overlays render as separate visible fragments rather than crossing collapsed rows.
- Manually expanding a collapse band turns the option switch off, and turning the switch on collapses every collapsible run across all grid pages.
