# FR-012: Maintain An Optional Event Scheduled Span

Anyone with an event link shall be able to save, replace, or clear an optional [Event Scheduled Span](../../../terminology/glossary.md#event-scheduled-span).

## Acceptance Criteria

- For a [Timed Event](../../../terminology/glossary.md#timed-event), the [Timed Event Scheduled Span](../../../terminology/glossary.md#timed-event-scheduled-span) is a time range.
- For a [Dates-Only Event](../../../terminology/glossary.md#dates-only-event), the [Dates-Only Event Scheduled Span](../../../terminology/glossary.md#dates-only-event-scheduled-span) is a single date.
