# FR-012: Maintain An Optional Event Occurrence Span

The [Event Owner](../../../terminology/glossary.md#event-owner) shall be able to save, replace, or clear an optional [Event Occurrence Span](../../../terminology/glossary.md#event-occurrence-span).
Other [Event Visitors](../../../terminology/glossary.md#event-visitor) shall not be able to change it.

## Acceptance Criteria

- For a [Timed Event](../../../terminology/glossary.md#timed-event), the [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span) is a time range.
- For a [Dates-Only Event](../../../terminology/glossary.md#dates-only-event), the [Dates-Only Event Occurrence Span](../../../terminology/glossary.md#dates-only-event-occurrence-span) is a single date.
