# FR-012: Maintain An Optional Scheduled Event Time

Anyone with an event link shall be able to save, replace, or clear an optional [Scheduled Event Time](../../../terminology/glossary.md#scheduled-event-time).

## Acceptance Criteria

- For a [Timed Event](../../../terminology/glossary.md#timed-event), the [Scheduled Event Time](../../../terminology/glossary.md#scheduled-event-time) is a time range.
- For a [Dates-Only Event](../../../terminology/glossary.md#dates-only-event), the [Scheduled Event Time](../../../terminology/glossary.md#scheduled-event-time) is a single date.
