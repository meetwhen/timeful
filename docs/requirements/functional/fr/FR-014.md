# FR-014: Derive Timed Grid Cell States From Event Domains

[Timed Grids](../../../terminology/glossary.md#timed-grid) shall derive
[Active Slots](../../../terminology/glossary.md#active-slots),
[Enabled Inactive Slots](../../../terminology/glossary.md#enabled-inactive-slot),
and [Disabled Padding Cells](../../../terminology/glossary.md#disabled-padding-cell)
from the [Enabled Slots](../../../terminology/glossary.md#enabled-slots) domain.

## Acceptance Criteria

- In [Custom Domain Editing](../../../terminology/glossary.md#custom-domain-editing), [Active Slots](../../../terminology/glossary.md#active-slots) are selected, [Enabled Inactive Slots](../../../terminology/glossary.md#enabled-inactive-slot) remain editable, and cells outside the [Enabled Slots](../../../terminology/glossary.md#enabled-slots) domain are non-editable padding.
- On a [Custom Domain Mode](../../../terminology/glossary.md#custom-domain-mode) event page, the grid axis uses the [Saved Active-Range Band](../../../terminology/glossary.md#saved-active-range-band), falling back to the [Enabled Slots](../../../terminology/glossary.md#enabled-slots) domain. The full civil-day axis appears only in [Custom Domain Editing](../../../terminology/glossary.md#custom-domain-editing) or when [Show all hours](../../../terminology/glossary.md#show-all-hours) is enabled.
- On a [Custom Domain Mode](../../../terminology/glossary.md#custom-domain-mode) event page, [Active Slots](../../../terminology/glossary.md#active-slots) are respondent-selectable and [Enabled Inactive Slots](../../../terminology/glossary.md#enabled-inactive-slot) are not respondent-selectable.
- [Ranged Domain Mode](../../../terminology/glossary.md#ranged-domain-mode) grids render the [Active Slot Range](../../../terminology/glossary.md#active-slot-range) with hour-aligned axis boundaries.
- [Enabled Inactive Slots](../../../terminology/glossary.md#enabled-inactive-slot) are light grey, and [Disabled Padding Cells](../../../terminology/glossary.md#disabled-padding-cell) are dark grey.
