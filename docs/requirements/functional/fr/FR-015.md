# FR-015: Save Active Slots Only Within The Enabled Domain

When a timed specific-date event is saved, the system shall discard each
[Active Slot](../../../terminology/glossary.md#active-slots) outside that event's
[Enabled Slots](../../../terminology/glossary.md#enabled-slots) domain.
