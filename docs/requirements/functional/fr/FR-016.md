# FR-016: Limit Scheduling To Active Slots

On a [Timed Event](../../../terminology/glossary.md#timed-event) page while scheduling or rescheduling an event, the system shall allow a schedule drag to start and end only on [Active Slots](../../../terminology/glossary.md#active-slots).

When a drag moves into an [Inactive Slot](../../../terminology/glossary.md#inactive-slots), the schedule selection shall retain its last [Active Slot](../../../terminology/glossary.md#active-slots) endpoint.
