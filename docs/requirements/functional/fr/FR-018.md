# FR-018: Restrict Event Settings Editing To The Event Owner

Only the [Event Owner](../../../terminology/glossary.md#event-owner) presenting
a valid [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token)
may edit an event's [Event Settings](../../../terminology/glossary.md#event-settings).

Other [Event Visitors](../../../terminology/glossary.md#event-visitor) shall
receive [Event Settings](../../../terminology/glossary.md#event-settings) as
read-only and shall not be able to save changes.
