# FR-018: Restrict Event Settings Editing To The Event Owner

Only the [Event Owner](../../../terminology/glossary.md#event-owner) may edit an event's [Event Settings](../../../terminology/glossary.md#event-settings).
The system shall provide the **Event Settings** editing form to that owner and shall authorize the edit through either a valid [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token) or the [Platform Identity](../../../terminology/glossary.md#platform-identity) associated with that event ownership.

Other [Event Visitors](../../../terminology/glossary.md#event-visitor) shall receive [Event Settings](../../../terminology/glossary.md#event-settings) as read-only and shall not be able to save changes.
An [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token) shall authorize **Event Settings** edits only, not [Availability Response](../../../terminology/glossary.md#availability-response) edits.
