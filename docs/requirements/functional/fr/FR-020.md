# FR-020: Keep The Mobile Selected Time Slot Tooltip Available After Scrolling

On a mobile event page, a selected [Time Slot](../../../terminology/glossary.md#time-slot) shall remain selected while the user scrolls.

When that selected [Time Slot](../../../terminology/glossary.md#time-slot) is visible in the [Timed Grid](../../../terminology/glossary.md#timed-grid), its time-and-date tooltip shall be visible adjacent to it.
No tooltip shall be visible when no **Time Slot** is selected.
