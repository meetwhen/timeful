# FR-020: Keep The Mobile Selected Timed Slot Tooltip Available After Scrolling

On a mobile event page, a selected [Timed Slot](../../../terminology/glossary.md#timed-slot) shall remain selected while the user scrolls.

When that selected [Timed Slot](../../../terminology/glossary.md#timed-slot) is visible in the [Timed Grid](../../../terminology/glossary.md#timed-grid), its time-and-date tooltip shall be visible adjacent to it.
No tooltip shall be visible when no **Timed Slot** is selected.
