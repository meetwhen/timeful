# FR-024: Keep The Event Time Format And Display Time Format Independent

The [Event Time Format](../../../terminology/glossary.md#event-time-format) shall control times in event editor forms, and the [Display Time Format](../../../terminology/glossary.md#display-time-format) shall control times in event-page grids and tooltips.

Changing either format shall not change the other format.

## Acceptance Criteria

- The [Event Time Format](../../../terminology/glossary.md#event-time-format) persists as an event-editor preference.
- The [Display Time Format](../../../terminology/glossary.md#display-time-format) persists as an event-page preference and applies across event pages.
