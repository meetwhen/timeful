# FR-026: Define Event Kind Values

An [Event Kind](../../../terminology/glossary.md#event-kind) shall be either a [Timed Event](../../../terminology/glossary.md#timed-event), displayed as `Dates and times`, or a [Dates-Only Event](../../../terminology/glossary.md#dates-only-event), displayed as `Dates only`.
