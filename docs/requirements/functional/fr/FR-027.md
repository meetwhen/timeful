# FR-027: Restrict Dates-Only Event Timezone Settings To The Event Owner

A [Dates-Only Event](../../terminology/glossary.md#dates-only-event) shall expose its [Event Timezone](../../terminology/glossary.md#event-timezone) in [Event Settings](../../terminology/glossary.md#event-settings) only to the [Event Owner](../../terminology/glossary.md#event-owner).

The [Event Owner](../../terminology/glossary.md#event-owner) may change and save the [Event Timezone](../../terminology/glossary.md#event-timezone).
