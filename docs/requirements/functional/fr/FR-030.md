# FR-030: Persist Only Active Time Slots In Browser Storage

For a [Timed Event](../../../terminology/glossary.md#timed-event), the browser shall store only [Active Slots](../../../terminology/glossary.md#active-slots) and shall derive the [Enabled Domain](../../../terminology/glossary.md#enabled-domain) from the event's canonical **Timed Event** state.
