# FR-030: Persist Only Active Timed Slots In Browser Storage

For a [Timed Event](../../../terminology/glossary.md#timed-event), the browser shall store only [Active Slots](../../../terminology/glossary.md#active-slots) and shall derive the [Enabled Slots](../../../terminology/glossary.md#enabled-slots) domain from the event's canonical **Timed Event** state.
