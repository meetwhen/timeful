# FR-034: Gate The Discord Banner With An Environment Flag

When its environment flag is enabled, the frontend shall show the Discord banner only on the landing page and only on non-phone viewports.

The flag shall default to disabled.

A visitor who dismisses the banner shall not see it again in that browser.
