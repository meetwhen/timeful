# FR-035: Create And Edit Events With Optional Descriptions

While creating or editing an event, the [Event Owner](../../../terminology/glossary.md#event-owner) shall be able to enter an optional event description in [Event Settings](../../../terminology/glossary.md#event-settings).
The system shall preserve the description provided at creation or edit with the event.
