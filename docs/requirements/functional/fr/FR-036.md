# FR-036: Reset The Display Timezone To The Event Timezone

On a [Timed Event](../../terminology/glossary.md#timed-event) page, resetting the [Display Timezone](../../terminology/glossary.md#display-timezone) shall set it to the [Event Timezone](../../terminology/glossary.md#event-timezone).
