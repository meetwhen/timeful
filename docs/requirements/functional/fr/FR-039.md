# FR-039: Show Event Settings To Non-Owners

An [Event Visitor](../../../terminology/glossary.md#event-visitor) other than the [Event Owner](../../../terminology/glossary.md#event-owner) shall be able to open a read-only view of an event's [Event Settings](../../../terminology/glossary.md#event-settings).
