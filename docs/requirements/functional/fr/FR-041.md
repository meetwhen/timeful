# FR-041: Cue Availability Editing From Unavailable Timed Grid Areas

When an [Event Visitor](../../../terminology/glossary.md#event-visitor) selects
an unavailable area of a [Timed Grid](../../../terminology/glossary.md#timed-grid)
on a [Timed Event](../../../terminology/glossary.md#timed-event) page in read
mode, the applicable Add availability or Edit availability action shall blink
to cue [Availability Editing](../../../terminology/glossary.md#availability-editing).
