# FR-044: Explain Protected Responses

In the event-page Responses view, selecting the access icon for a [Protected Response](../../../terminology/glossary.md#protected-response) that the current [Event Visitor](../../../terminology/glossary.md#event-visitor) cannot edit shall display a tooltip that explains why it is not editable.
