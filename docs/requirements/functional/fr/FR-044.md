# FR-044: Explain Protected Event Responses

In the event-page Responses view, selecting the access icon for a [Protected Event Response](../../../terminology/glossary.md#protected-event-response) that the current [Event Visitor](../../../terminology/glossary.md#event-visitor) cannot edit shall display a tooltip that explains why it is not editable.
