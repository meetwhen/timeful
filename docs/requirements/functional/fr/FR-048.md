# FR-048: Center The No-Response Mobile Collapse disabled times Control

On a mobile [Timed Event](../../../terminology/glossary.md#timed-event) page with no responses, the ["Collapse disabled times" Option](../../../terminology/glossary.md#collapse-disabled-times-option) shall be centered inside its column.
