# FR-048: Center The No-Response Mobile Show All Hours Control

On a mobile [Timed Event](../../../terminology/glossary.md#timed-event) page
with no responses, the [Show all hours](../../../terminology/glossary.md#show-all-hours)
control
shall be centered inside its column.
