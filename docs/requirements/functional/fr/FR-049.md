# FR-049: Arrange Mobile Event-Page Controls In Two Rows

On a mobile event page with one or more responses, Show best times or Show best
days and More options shall appear in the first row.

On a mobile [Timed Event](../../../terminology/glossary.md#timed-event) page, the [Display Time Format](../../../terminology/glossary.md#display-time-format), [Display Timezone](../../../terminology/glossary.md#display-timezone), and
number-of-days controls shall appear in the second row. [Dates-Only Event](../../../terminology/glossary.md#dates-only-event) pages
shall not show those timed-event controls.
