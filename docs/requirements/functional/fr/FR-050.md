# FR-050: Generate Active Slots For Newly Added Event Picked Dates

When an event in [Range Timed Domain Mode](../../../terminology/glossary.md#range-timed-domain-mode) gains an [Event Picked Date](../../../terminology/glossary.md#event-picked-dates), the system shall generate [Active Slots](../../../terminology/glossary.md#active-slots) of the configured [Slot Duration](../../../terminology/glossary.md#slot-duration) for that date from its [Active Slot Range](../../../terminology/glossary.md#active-slot-range) in the [Event Timezone](../../../terminology/glossary.md#event-timezone).

## Acceptance Criteria

- The [Active Slot Range](../../../terminology/glossary.md#active-slot-range) start is inclusive and its end is exclusive.
  For a 15-minute `09:00-17:00` range, [Active Slots](../../../terminology/glossary.md#active-slots) beginning at `09:00` through `16:45` are active.
- An [Active Slot Range](../../../terminology/glossary.md#active-slot-range) does not cross midnight in the [Event Timezone](../../../terminology/glossary.md#event-timezone).
