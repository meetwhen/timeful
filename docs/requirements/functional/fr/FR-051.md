# FR-051: Keep Active Slots Off Newly Added Event Picked Dates In Custom Timed Domain Mode

When an event in [Custom Timed Domain Mode](../../../terminology/glossary.md#custom-timed-domain-mode) gains an [Event Picked Date](../../../terminology/glossary.md#event-picked-dates), the system shall add that date's full [Enabled Domain](../../../terminology/glossary.md#enabled-domain) without adding [Active Slots](../../../terminology/glossary.md#active-slots).
