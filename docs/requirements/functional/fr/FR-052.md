# FR-052: Remove Active Slots For Removed Picked Dates

When a [Timed Event](../../../terminology/glossary.md#timed-event) removes a [Picked Date](../../../terminology/glossary.md#picked-dates), the system shall remove every [Active Slot](../../../terminology/glossary.md#active-slots) for that date.
