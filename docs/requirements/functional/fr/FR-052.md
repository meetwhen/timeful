# FR-052: Remove Active Slots For Removed Event Picked Dates

When a [Timed Event](../../../terminology/glossary.md#timed-event) removes an [Event Picked Date](../../../terminology/glossary.md#event-picked-dates), the system shall remove every [Active Slot](../../../terminology/glossary.md#active-slots) for that date.
