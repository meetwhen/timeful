# FR-053: Preserve Active Slots When Converting To Custom Domain Mode

An [Event Owner](../../../terminology/glossary.md#event-owner) shall be able to convert an event from [Ranged Domain Mode](../../../terminology/glossary.md#ranged-domain-mode) to [Custom Domain Mode](../../../terminology/glossary.md#custom-domain-mode). The [Active Slots](../../../terminology/glossary.md#active-slots) generated from its [Active Slot Range](../../../terminology/glossary.md#active-slot-range) shall be preserved as the initial custom selection.
