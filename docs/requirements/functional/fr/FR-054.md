# FR-054: Regenerate Active Slots When Converting To Range Timed Domain Mode

An [Event Owner](../../../terminology/glossary.md#event-owner) shall be able to convert an event from [Custom Timed Domain Mode](../../../terminology/glossary.md#custom-timed-domain-mode) to [Range Timed Domain Mode](../../../terminology/glossary.md#range-timed-domain-mode).
The system shall regenerate [Active Slots](../../../terminology/glossary.md#active-slots) for every [Event Picked Date](../../../terminology/glossary.md#event-picked-dates) from the [Active Slot Range](../../../terminology/glossary.md#active-slot-range), interpreted in the [Event Timezone](../../../terminology/glossary.md#event-timezone).
