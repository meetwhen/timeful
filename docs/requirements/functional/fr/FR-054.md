# FR-054: Regenerate Active Slots When Converting To Ranged Domain Mode

An [Event Owner](../../../terminology/glossary.md#event-owner) shall be able to convert an event from [Custom Domain Mode](../../../terminology/glossary.md#custom-domain-mode) to [Ranged Domain Mode](../../../terminology/glossary.md#ranged-domain-mode).
The system shall regenerate [Active Slots](../../../terminology/glossary.md#active-slots) for every [Picked Date](../../../terminology/glossary.md#picked-dates) from the [Active Slot Range](../../../terminology/glossary.md#active-slot-range), interpreted in the [Event Timezone](../../../terminology/glossary.md#event-timezone).
