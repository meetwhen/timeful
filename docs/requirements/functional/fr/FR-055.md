# FR-055: Persist Changed Timed Event Timezones

When an [Event Owner](../../../terminology/glossary.md#event-owner) saves a changed [Event Timezone](../../../terminology/glossary.md#event-timezone) for a [Timed Event](../../../terminology/glossary.md#timed-event), later editing and display of that event shall use the saved timezone.
