# FR-056: Preserve Active Slot Settings On No-Op Saves

Saving an unchanged [Timed Event](../../terminology/glossary.md#timed-event) shall preserve its [Picked Dates](../../terminology/glossary.md#picked-dates), [Active Slots](../../terminology/glossary.md#active-slots), [Event Timezone](../../terminology/glossary.md#event-timezone), and [Active Slot Settings](../../terminology/glossary.md#active-slot-settings).
