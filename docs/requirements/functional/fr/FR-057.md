# FR-057: Apply Timed Event Timezone Transition Rules

When a [Timed Event's](../../../terminology/glossary.md#timed-event) [Event Timezone](../../../terminology/glossary.md#event-timezone) changes, the system shall keep its [Picked Dates](../../../terminology/glossary.md#picked-dates) stable, rebuild its [Enabled Slots](../../../terminology/glossary.md#enabled-slots) domain, and discard each [Active Slot](../../../terminology/glossary.md#active-slots) outside that rebuilt domain.

The system shall discard from each [Availability Response](../../../terminology/glossary.md#availability-response) each selected slot whose corresponding [Active Slot](../../../terminology/glossary.md#active-slots) was discarded.
