# FR-057: Apply Timed Event Timezone Transition Rules

When a [Timed Event's](../../../terminology/glossary.md#timed-event) [Event Timezone](../../../terminology/glossary.md#event-timezone) changes, the system shall keep its [Event Picked Dates](../../../terminology/glossary.md#event-picked-dates) stable, rebuild its [Enabled Domain](../../../terminology/glossary.md#enabled-domain), and apply the [Wipe Rule](../../../terminology/glossary.md#wipe-rule) to its [Active Slots](../../../terminology/glossary.md#active-slots).

The system shall discard from each [Event Response](../../../terminology/glossary.md#event-response) each selected [Slot](../../../terminology/glossary.md#slot) whose corresponding [Active Slot](../../../terminology/glossary.md#active-slots) was discarded.
