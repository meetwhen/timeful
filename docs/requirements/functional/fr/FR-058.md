# FR-058: Reject Availability Outside The Enabled Domain

The system shall reject an [Event Response](../../../terminology/glossary.md#event-response) containing a [Time Slot](../../../terminology/glossary.md#time-slot) outside the event's [Active Slots](../../../terminology/glossary.md#active-slots) or a dates-only value outside the event's [Event Picked Dates](../../../terminology/glossary.md#event-picked-dates).
