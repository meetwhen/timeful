# FR-058: Reject Availability Outside The Event Domain

The system shall reject an [Availability Response](../../../terminology/glossary.md#availability-response) containing a timed slot outside the event's [Active Slots](../../../terminology/glossary.md#active-slots) or a dates-only value outside the event's selected dates.
