# FR-060: Create Protected Event Responses By Default

The system shall create each new [Event Response](../../../terminology/glossary.md#event-response) as a [Protected Event Response](../../../terminology/glossary.md#protected-event-response) owned by the creating [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity), unless its [Event Guest](../../../terminology/glossary.md#event-guest) explicitly makes it an [Open Event Response](../../../terminology/glossary.md#open-event-response).
