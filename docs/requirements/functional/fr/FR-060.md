# FR-060: Create Protected Responses By Default

The system shall create each new [Availability Response](../../../terminology/glossary.md#availability-response) as a [Protected Response](../../../terminology/glossary.md#protected-response) owned by the creating [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity), unless its [Event Guest](../../../terminology/glossary.md#event-guest) explicitly makes it an [Open Response](../../../terminology/glossary.md#open-response).
