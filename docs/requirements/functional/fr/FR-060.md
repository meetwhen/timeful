# FR-060: Create Protected Responses By Default

The system shall create each new [Protected Response](../../terminology/glossary.md#protected-response) unless its [Event Guest](../../terminology/glossary.md#event-guest) explicitly makes it an [Open Response](../../terminology/glossary.md#open-response).
