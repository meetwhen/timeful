# FR-061: Allow Event Guests To Open Their Availability Responses

An [Event Guest](../../../terminology/glossary.md#event-guest) shall be able to
change an [Availability Response](../../../terminology/glossary.md#availability-response)
owned by the guest's [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity)
from [Protected Response](../../../terminology/glossary.md#protected-response)
to an [Open Response](../../../terminology/glossary.md#open-response).
Any
[Event Visitor](../../../terminology/glossary.md#event-visitor) may edit an open
response.
