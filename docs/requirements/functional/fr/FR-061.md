# FR-061: Allow Event Guests To Open Their Event Responses

An [Event Guest](../../../terminology/glossary.md#event-guest) shall be able to change an [Event Response](../../../terminology/glossary.md#event-response) owned by the guest's [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) from [Protected Event Response](../../../terminology/glossary.md#protected-event-response) to an [Open Event Response](../../../terminology/glossary.md#open-event-response).
Any [Event Visitor](../../../terminology/glossary.md#event-visitor) may edit an [Open Event Response](../../../terminology/glossary.md#open-event-response).
