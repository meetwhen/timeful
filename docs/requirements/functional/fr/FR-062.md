# FR-062: Restore Event Guest Access After Event Sign-In

When an [Anonymous Event Visitor](../../../terminology/glossary.md#anonymous-event-visitor)
proves browser-local ownership of their [Event Guest](../../../terminology/glossary.md#event-guest)
and signs in to manage availability responses, the system shall associate that
event guest with the authenticated account. On another device, the authenticated
account shall be able to edit that event guest's
[Protected Responses](../../../terminology/glossary.md#protected-response) for
the event.
