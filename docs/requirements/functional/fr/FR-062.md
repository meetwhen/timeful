# FR-062: Restore Event Guest Access After Event Sign-In

When an [Event Guest](../../../terminology/glossary.md#event-guest) proves their browser-local identity and signs in to manage an event, the system shall associate that Event Guest with the authenticated account. On another device, the authenticated account shall be able to edit that Event Guest's [Protected Responses](../../../terminology/glossary.md#protected-response) for the event.
