# FR-062: Restore Event Guest Access After Event Sign-In

When an [Anonymous Event Visitor](../../../terminology/glossary.md#anonymous-event-visitor)
proves ownership of an existing [Protected Response](../../../terminology/glossary.md#protected-response)
with its applicable [Availability Response Edit Credential](../../../terminology/glossary.md#availability-response-edit-credential)
and signs in, the system shall associate the response's
[Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity)
with the visitor's [Platform Identity](../../../terminology/glossary.md#platform-identity)
for protected-response recovery.

On another device, a [Platform Identity](../../../terminology/glossary.md#platform-identity)
shall be able to edit every [Protected Response](../../../terminology/glossary.md#protected-response)
created by an associated [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity).
For an event not owned by that Platform Identity, association of a new Event
Visitor Identity alone shall not authorize a protected response created by a
different Event Visitor Identity.
