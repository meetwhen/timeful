# FR-063: Associate The Event Owner After Event Sign-In

When an [Anonymous Event Visitor](../../../terminology/glossary.md#anonymous-event-visitor)
who is an [Event Owner](../../../terminology/glossary.md#event-owner) proves
their [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token)
and signs in to manage the event, the system shall associate that event owner
with the authenticated account. On another device, that account shall be able
to manage the event.
