# FR-063: Associate The Event Owner After Event Sign-In

When an [Anonymous Event Visitor](../../../terminology/glossary.md#anonymous-event-visitor) who is an [Event Owner](../../../terminology/glossary.md#event-owner) proves a valid [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token) and signs in, the system shall associate that event ownership with the visitor's [Platform Identity](../../../terminology/glossary.md#platform-identity).

When a [Platform Identity](../../../terminology/glossary.md#platform-identity) associated with an event ownership opens that event in another browser, the system shall associate the new [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) and permit [Event Settings](../../../terminology/glossary.md#event-settings) management without requiring the original [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token).
