# FR-063: Associate The Event Owner After Event Sign-In

When an anonymous [Event Owner](../../../terminology/glossary.md#event-owner) proves their browser-local event ownership and signs in to manage the event, the system shall associate that Event Owner with the authenticated account. On another device, that account shall be able to manage the event.
