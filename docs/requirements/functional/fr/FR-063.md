# FR-063: Associate The Event Owner After Event Sign-In

When an [Anonymous Event Visitor](../../../terminology/glossary.md#anonymous-event-visitor) who is an [Event Owner](../../../terminology/glossary.md#event-owner) proves a valid [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token) and signs in, the system shall associate that event ownership with the visitor's [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity).

When a [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity) associated with an event ownership opens that event in another browser, the system shall associate the new [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) and permit [Event Settings](../../../terminology/glossary.md#event-settings) management without requiring the original [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token).

Event ownership shall be associated with exactly one [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity).
When a signed-in visitor proves a valid [Event Owner Edit Token](../../../terminology/glossary.md#event-owner-edit-token) for an event already associated with a different **Platform Visitor Identity**, the system shall move that event ownership to the proving visitor's identity, and the previously associated identity shall lose [Event Settings](../../../terminology/glossary.md#event-settings) authority.

For an anonymous [Event Owner](../../../terminology/glossary.md#event-owner), clearing the browser's local data forfeits the **Event Owner Edit Token** with no recovery path, leaving the event permanently unmanageable; this lockout is accepted current behavior.
A signed-in **Event Owner** recovers authority in a new browser through the association this requirement defines.
