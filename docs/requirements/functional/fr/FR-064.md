# FR-064: Keep Protected Event Responses In Schedule Overlap

Outside [Blind Availability Mode](../../../terminology/glossary.md#blind-availability-mode), the event page shall include a [Protected Event Response](../../../terminology/glossary.md#protected-event-response) that the current [Event Visitor](../../../terminology/glossary.md#event-visitor) cannot edit, and shall include its availability in [Schedule Overlap](../../../terminology/glossary.md#schedule-overlap) views.
