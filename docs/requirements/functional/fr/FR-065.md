# FR-065: Show Availability Responses For Availability Editing

Outside [Blind Availability](../../../terminology/glossary.md#blind-availability), when an [Event Visitor](../../../terminology/glossary.md#event-visitor) opens
[Availability Editing](../../../terminology/glossary.md#availability-editing),
the system shall list every [Availability Response](../../../terminology/glossary.md#availability-response),
including [Protected Responses](../../../terminology/glossary.md#protected-response)
the event visitor cannot edit. It shall permit editing only for availability
responses the event visitor is authorized to edit.

## Acceptance Criteria

- Outside [Blind Availability](../../../terminology/glossary.md#blind-availability), before the [Event Visitor](../../../terminology/glossary.md#event-visitor)
  selects an availability-response subset, the list orders availability
  responses owned by the visitor's [Event Guest](../../../terminology/glossary.md#event-guest)
  first, then other [Open Responses](../../../terminology/glossary.md#open-response),
  then other [Protected Responses](../../../terminology/glossary.md#protected-response).
