# FR-066: Filter The Response-Editing Grid By Event Response Selection

Outside [Blind Availability Mode](../../../terminology/glossary.md#blind-availability-mode), in [Availability Editing](../../../terminology/glossary.md#availability-editing), an [Event Visitor](../../../terminology/glossary.md#event-visitor) may select [Event Responses](../../../terminology/glossary.md#event-response) regardless of whether they are authorized to edit them.
When one or more responses are selected, the response-editing grid shall show availability and calculate [Schedule Overlap](../../../terminology/glossary.md#schedule-overlap) only for the selected responses.

## Acceptance Criteria

- Outside [Blind Availability Mode](../../../terminology/glossary.md#blind-availability-mode), initially, the grid shows every [Event Response's](../../../terminology/glossary.md#event-response) availability and no response checkbox is selected.
- Selecting an [Event Response](../../../terminology/glossary.md#event-response) moves it before unselected **Event Responses** while preserving the prior relative order within the selected and unselected groups.
- Changing the selection shall not change which [Event Responses](../../../terminology/glossary.md#event-response) the [Event Visitor](../../../terminology/glossary.md#event-visitor) is authorized to edit.
- Clearing the final selected [Event Response](../../../terminology/glossary.md#event-response) restores every **Event Response's** availability and overlap calculation.
- Reloading the page restores the initial selection state.
