# FR-066: Filter The Availability-Editor Grid By Availability Response Selection

In availability editing, a visitor may select [Availability Responses](../../../terminology/glossary.md#availability-response) regardless of whether they are authorized to edit them. When one or more responses are selected, the grid shall show availability and calculate overlaps only for the selected responses.

## Acceptance Criteria

- Initially, the grid shows every [Availability Response](../../../terminology/glossary.md#availability-response)'s availability and no response checkbox is selected.
- Selecting an [Availability Response](../../../terminology/glossary.md#availability-response) moves it before unselected availability responses while preserving the prior relative order within the selected and unselected groups.
- Changing the selection shall not change which [Availability Responses](../../../terminology/glossary.md#availability-response) the visitor is authorized to edit.
- Clearing the final selected [Availability Response](../../../terminology/glossary.md#availability-response) restores every availability response's availability and overlap calculation.
- Reloading the page restores the initial selection state.
