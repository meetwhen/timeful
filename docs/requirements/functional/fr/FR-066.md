# FR-066: Filter The Availability Editor Grid By Availability Response Selection

Outside [Blind Availability](../../../terminology/glossary.md#blind-availability), in [Availability Editing](../../../terminology/glossary.md#availability-editing), an [Event Visitor](../../../terminology/glossary.md#event-visitor) may select [Availability Responses](../../../terminology/glossary.md#availability-response) regardless of whether they are authorized to edit them.
When one or more responses are selected, the [Availability Editor](../../../terminology/glossary.md#availability-editor) shall show availability and calculate [Schedule Overlap](../../../terminology/glossary.md#schedule-overlap) only for the selected responses.

## Acceptance Criteria

- Outside [Blind Availability](../../../terminology/glossary.md#blind-availability), initially, the grid shows every [Availability Response](../../../terminology/glossary.md#availability-response)'s availability and no response checkbox is selected.
- Selecting an [Availability Response](../../../terminology/glossary.md#availability-response) moves it before unselected availability responses while preserving the prior relative order within the selected and unselected groups.
- Changing the selection shall not change which [Availability Responses](../../../terminology/glossary.md#availability-response) the [Event Visitor](../../../terminology/glossary.md#event-visitor) is authorized to edit.
- Clearing the final selected [Availability Response](../../../terminology/glossary.md#availability-response) restores every availability response's availability and overlap calculation.
- Reloading the page restores the initial selection state.
