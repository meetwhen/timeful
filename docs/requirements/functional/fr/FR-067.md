# FR-067: Create Custom Domain Mode Timed Events

When creating a [Timed Event](../../../terminology/glossary.md#timed-event), an [Event Owner](../../../terminology/glossary.md#event-owner) shall be able to select [Custom Domain Mode](../../../terminology/glossary.md#custom-domain-mode) and choose its [Active Slots](../../../terminology/glossary.md#active-slots) in [Custom Domain Editing](../../../terminology/glossary.md#custom-domain-editing) before saving.

## Acceptance Criteria

- [Custom Domain Editing](../../../terminology/glossary.md#custom-domain-editing) shall not be available in [Ranged Domain Mode](../../../terminology/glossary.md#ranged-domain-mode).
- [Custom Domain Editing](../../../terminology/glossary.md#custom-domain-editing) shall change [Active Slots](../../../terminology/glossary.md#active-slots) without changing [Picked Dates](../../../terminology/glossary.md#picked-dates).
