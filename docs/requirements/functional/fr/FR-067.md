# FR-067: Create Timed Events In Custom Timed Domain Mode

When creating a [Timed Event](../../../terminology/glossary.md#timed-event), an [Event Owner](../../../terminology/glossary.md#event-owner) shall be able to select [Custom Timed Domain Mode](../../../terminology/glossary.md#custom-timed-domain-mode) and choose its [Active Slots](../../../terminology/glossary.md#active-slots) in [Custom Timed Domain Editing](../../../terminology/glossary.md#custom-timed-domain-editing) before saving.

## Acceptance Criteria

- [Custom Timed Domain Editing](../../../terminology/glossary.md#custom-timed-domain-editing) shall not be available in [Range Timed Domain Mode](../../../terminology/glossary.md#range-timed-domain-mode).
- [Custom Timed Domain Editing](../../../terminology/glossary.md#custom-timed-domain-editing) shall change [Active Slots](../../../terminology/glossary.md#active-slots) without changing [Event Picked Dates](../../../terminology/glossary.md#event-picked-dates).
