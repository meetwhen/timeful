# FR-068: Regenerate Active Slots When The Active Slot Range Changes

When an [Event Owner](../../../terminology/glossary.md#event-owner) changes the [Active Slot Range](../../../terminology/glossary.md#active-slot-range) of a [Ranged Domain Mode](../../../terminology/glossary.md#ranged-domain-mode) event, the system shall regenerate its [Active Slots](../../../terminology/glossary.md#active-slots) for every [Picked Date](../../../terminology/glossary.md#picked-dates).
