# FR-069: Calculate Schedule Overlap From Availability States

[Schedule Overlap](../../../terminology/glossary.md#schedule-overlap) views shall calculate overlap from each included [Availability State](../../../terminology/glossary.md#availability-state): [Available](../../../terminology/glossary.md#available) and [If needed](../../../terminology/glossary.md#if-needed) shall contribute equally, and [Unavailable](../../../terminology/glossary.md#unavailable) shall not contribute.
