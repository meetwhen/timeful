# FR-069: Calculate Schedule Overlap From Availability Statuses

[Schedule Overlap](../../../terminology/glossary.md#schedule-overlap) views shall calculate overlap from each included [Availability Status](../../../terminology/glossary.md#availability-status): [Available](../../../terminology/glossary.md#available) and [If needed](../../../terminology/glossary.md#if-needed) shall contribute equally, and [Unavailable](../../../terminology/glossary.md#unavailable) shall not contribute.
