# FR-069: Calculate Schedule Overlap From Availability States

[Schedule Overlap](../../../terminology/glossary.md#schedule-overlap) views shall calculate overlap from each included [Availability State](../../../terminology/glossary.md#availability-state): Available and If needed shall contribute equally, and Unavailable shall not contribute.
