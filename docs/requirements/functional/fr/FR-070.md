# FR-070: Omit Advertising When Freemium Mode Is Disabled

When Freemium Mode is disabled, the frontend shall not render advertising surfaces or register third-party advertising scripts.

Rejected on 2026-08-30 when the freemium apparatus was removed from the product and all functionality became ungated.
