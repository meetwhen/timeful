# FR-071: Remove Advertising Layout Reservations When Freemium Mode Is Disabled

When Freemium Mode is disabled, the frontend shall not reserve layout or sticky space exclusively for advertising.

Rejected on 2026-08-30 when the freemium apparatus was removed from the product and all functionality became ungated.
