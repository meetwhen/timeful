# FR-072: Bypass Freemium Restrictions When Freemium Is Disabled

When [Freemium](../../../terminology/glossary.md#freemium) is disabled, the frontend shall not block a [Platform Visitor](../../../terminology/glossary.md#platform-visitor) with a **Freemium** paywall or show an upgrade prompt for a **Freemium**-gated action.
