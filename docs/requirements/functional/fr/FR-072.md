# FR-072: Bypass Freemium Mode Restrictions When Freemium Mode Is Disabled

When [Freemium Mode](../../../terminology/glossary.md#freemium-mode) is disabled, the frontend shall not block a [Platform Visitor](../../../terminology/glossary.md#platform-visitor) with a **Freemium Mode** paywall or show an upgrade prompt for a **Freemium Mode**-gated action.
