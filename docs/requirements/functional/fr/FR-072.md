# FR-072: Bypass Freemium Mode Restrictions When Freemium Mode Is Disabled

When Freemium Mode is disabled, the frontend shall not block a [Platform Visitor](../../../terminology/glossary.md#platform-visitor) with a Freemium Mode paywall or show an upgrade prompt for a Freemium Mode-gated action.

Rejected on 2026-08-30 when the freemium apparatus was removed from the product and all functionality became ungated.
