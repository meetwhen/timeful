# FR-073: Retain Browser-Local Event Visitor Identities

The browser shall establish and retain a non-authorizing, event-scoped
[Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity)
as an opaque `eventVisitorId` across browser sessions unless browser-local data
is cleared. It shall retain that identity when its [Platform Identity](../../../terminology/glossary.md#platform-identity)
signs out, and shall not use a raw Platform Identity value as the Event Visitor
Identity.

## Acceptance Criteria

- When an [Event Visitor](../../../terminology/glossary.md#event-visitor) opens
  an event, the browser establishes that event visitor's
  [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity).
- When event creation begins, the browser establishes the future
  [Event Owner](../../../terminology/glossary.md#event-owner)'s event visitor
  [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity)
  before the owner opens the event page.
