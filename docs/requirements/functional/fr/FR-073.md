# FR-073: Retain Browser-Local Event Guest Credentials

After an [Event Guest](../../../terminology/glossary.md#event-guest) creates a
[Protected Response](../../../terminology/glossary.md#protected-response), the
browser shall retain the browser-local credential needed to edit that response
after a reload.
