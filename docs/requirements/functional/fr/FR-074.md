# FR-074: Derive The Timed Event Enabled Domain

For each [Event Picked Date](../../../terminology/glossary.md#event-picked-dates) of a [Timed Event](../../../terminology/glossary.md#timed-event), the system shall derive [Enabled Domain](../../../terminology/glossary.md#enabled-domain) [Time Slots](../../../terminology/glossary.md#time-slot) of the configured [Slot Duration](../../../terminology/glossary.md#slot-duration), tiling the full [Civil Date](../../../terminology/glossary.md#civil-date) from 00:00 inclusive through the next 00:00 exclusive in the [Event Timezone](../../../terminology/glossary.md#event-timezone).
