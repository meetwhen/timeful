# FR-074: Derive The Specific-Date Timed-Event Enabled Domain

For each [Picked Date](../../../terminology/glossary.md#picked-dates) of a timed
specific-date event, the system shall derive [Enabled Slots](../../../terminology/glossary.md#enabled-slots)
at the event's configured increment for the full civil day from 00:00 inclusive
through the next 00:00 exclusive in the [Event Timezone](../../../terminology/glossary.md#event-timezone).
