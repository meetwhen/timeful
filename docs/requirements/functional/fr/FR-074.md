# FR-074: Derive The Timed Event Enabled Domain

For each [Picked Date](../../../terminology/glossary.md#picked-dates) of a [Timed Event](../../../terminology/glossary.md#timed-event), the system shall derive [Enabled Slots](../../../terminology/glossary.md#enabled-slots) at the event's configured [Slot Increment](../../../terminology/glossary.md#slot-increment) for the full [Civil Date](../../../terminology/glossary.md#civil-date) from 00:00 inclusive through the next 00:00 exclusive in the [Event Timezone](../../../terminology/glossary.md#event-timezone).
