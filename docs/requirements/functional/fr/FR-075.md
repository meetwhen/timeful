# FR-075: Generate Initial Range Timed Domain Mode Active Slots

When creating a [Range Timed Domain Mode](../../../terminology/glossary.md#range-timed-domain-mode) [Timed Event](../../../terminology/glossary.md#timed-event) with [Event Picked Dates](../../../terminology/glossary.md#event-picked-dates), the system shall generate [Active Slots](../../../terminology/glossary.md#active-slots) of the configured [Slot Duration](../../../terminology/glossary.md#slot-duration) for every **Event Picked Date** from its [Active Slot Range](../../../terminology/glossary.md#active-slot-range) in the [Event Timezone](../../../terminology/glossary.md#event-timezone).

## Acceptance Criteria

- The [Active Slot Range](../../../terminology/glossary.md#active-slot-range) start is inclusive and its end is exclusive.
- An [Active Slot Range](../../../terminology/glossary.md#active-slot-range) does not cross midnight in the [Event Timezone](../../../terminology/glossary.md#event-timezone).
