# FR-075: Generate Initial Ranged Timed Event Active Slots

When creating a [Ranged Domain Mode](../../../terminology/glossary.md#ranged-domain-mode) [Timed Event](../../../terminology/glossary.md#timed-event) with [Picked Dates](../../../terminology/glossary.md#picked-dates), the system shall generate [Active Slots](../../../terminology/glossary.md#active-slots) at the configured [Slot Increment](../../../terminology/glossary.md#slot-increment) for every picked date from its [Active Slot Range](../../../terminology/glossary.md#active-slot-range) in the [Event Timezone](../../../terminology/glossary.md#event-timezone).

## Acceptance Criteria

- The [Active Slot Range](../../../terminology/glossary.md#active-slot-range) start is inclusive and its end is exclusive.
- An [Active Slot Range](../../../terminology/glossary.md#active-slot-range) does not cross midnight in the [Event Timezone](../../../terminology/glossary.md#event-timezone).
