# FR-076: Separate The Mobile Event Action Bar From The Timed Grid

On a mobile [Timed Event](../../../terminology/glossary.md#timed-event) page, the system shall show the bottom event action bar on a white elevated surface that is visibly separated from the [Timed Grid](../../../terminology/glossary.md#timed-grid).
Availability colors remain reserved for [Availability Statuses](../../../terminology/glossary.md#availability-status) in the grid and availability actions.
