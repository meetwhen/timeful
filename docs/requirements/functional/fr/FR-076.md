# FR-076: Separate The Mobile Event Action Bar From The Timed Grid

On a mobile timed event page, the system shall show the bottom event action bar
on a white elevated surface that is visibly separated from the
[Timed Grid](../../../terminology/glossary.md#timed-grid).
Availability colors
remain reserved for availability states in the grid and availability actions.
