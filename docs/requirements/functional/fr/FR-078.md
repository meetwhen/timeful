# FR-078: Provide Mobile Header Navigation Actions

On phone-sized event and landing pages, the system shall provide a header navigation menu containing `Create an event` followed by `Give feedback`.

On a phone-sized event page, the header shall show the sign-in entry point when sign-in is enabled and the visitor is not signed in, followed by the navigation menu.
The navigation menu shall replace the separately displayed `Create an event` action.

On a phone-sized landing page, the header shall show the sign-in entry point when sign-in is enabled and the visitor is not signed in, followed by the navigation menu and the GitHub link.

On these phone-sized pages, `Give feedback` shall be available through the header navigation menu rather than as a separate event-page footer action or an individual header action.
The desktop header behavior is excluded.
