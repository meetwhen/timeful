# FR-079: Associate Event Visitor Identities With Platform Visitor Identities

When an [Event Visitor](../../../terminology/glossary.md#event-visitor) signs in, the system shall associate the [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) established in the browser performing the sign-in with the visitor's [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity).
One **Platform Visitor Identity** may be associated with multiple **Event Visitor Identities** for the same event when they originate in different browsers.

When an active [Granted Event Visitor Control Credential (Granted EVCC)](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc) makes another browser's [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) the response-owning source, associating that source identity follows the explicit confirmation [FR-062](FR-062.md) defines instead of this automatic association.

The association shall not make an [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) authorizing by itself or expose a raw [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity) value as an event or [Event Response](../../../terminology/glossary.md#event-response) identifier.
