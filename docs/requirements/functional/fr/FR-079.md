# FR-079: Associate Event Visitor Identities With Platform Identities

When an [Event Visitor](../../../terminology/glossary.md#event-visitor) signs in, the system shall associate that visitor's [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) with the visitor's [Platform Identity](../../../terminology/glossary.md#platform-identity).
One [Platform Identity](../../../terminology/glossary.md#platform-identity) may be associated with multiple [Event Visitor Identities](../../../terminology/glossary.md#event-visitor-identity) for the same event when they originate in different browsers.

The association shall not make an [Event Visitor Identity](../../../terminology/glossary.md#event-visitor-identity) authorizing by itself or expose a raw [Platform Identity](../../../terminology/glossary.md#platform-identity) value as an event or [Availability Response](../../../terminology/glossary.md#availability-response) identifier.
