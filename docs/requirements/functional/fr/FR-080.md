# FR-080: Default Signed-In Response Names From The Account Profile

When a signed-in [Event Guest](../../../terminology/glossary.md#event-guest)
creates an [Availability Response](../../../terminology/glossary.md#availability-response),
the system shall initialize its display name from the guest's [Platform Identity](../../../terminology/glossary.md#platform-identity)
first and last name.

The guest may change the display name. The system shall not change an existing
[Availability Response](../../../terminology/glossary.md#availability-response)
display name when the first or last name of the associated
[Platform Identity](../../../terminology/glossary.md#platform-identity) changes.
