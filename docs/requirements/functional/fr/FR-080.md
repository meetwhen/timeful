# FR-080: Default Signed-In Response Names From The Account Profile

When a signed-in [Event Guest](../../../terminology/glossary.md#event-guest) creates an [Event Response](../../../terminology/glossary.md#event-response), the system shall initialize its display name from the guest's [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity) first and last name.

The guest may change the display name.
The system shall not change an existing [Event Response](../../../terminology/glossary.md#event-response) display name when the first or last name of the associated [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity) changes.
