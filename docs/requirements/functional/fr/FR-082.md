# FR-082: Transfer Platform Sign-In From A PostgreSQL Event To Another Browser

A signed-in [Platform Visitor](../../../terminology/glossary.md#platform-visitor) at a PostgreSQL event shall be able to initiate an [Access Transfer](../../../terminology/glossary.md#access-transfer) that signs another browser in to the visitor's [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity).

When the target browser opens the transfer link, the system shall display a matching code and require the initiating browser to approve that exact code within five minutes of link creation before issuing a normal authenticated session to the target browser.
MongoDB transfer behavior is unchanged.
