# FR-084: Preserve Blind Availability Privacy

For an event using [Blind Availability](../../../terminology/glossary.md#blind-availability), a non-owner [Event Guest](../../../terminology/glossary.md#event-guest) shall be able to create and manage multiple [Availability Responses](../../../terminology/glossary.md#availability-response) that the guest is authorized to manage.

The system shall expose to that non-owner only the availability responses the
guest is authorized to manage.
It shall not expose other responses, their
availability, their identities, or their count through event payloads,
availability editing, response selection, or schedule-overlap views.
The
[Event Owner](../../../terminology/glossary.md#event-owner) shall be able to
view every availability response.
