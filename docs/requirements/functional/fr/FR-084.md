# FR-084: Preserve Blind Availability Mode Privacy

For an event using [Blind Availability Mode](../../../terminology/glossary.md#blind-availability-mode), a non-owner [Event Guest](../../../terminology/glossary.md#event-guest) shall be able to create and manage multiple [Event Responses](../../../terminology/glossary.md#event-response) that the guest is authorized to manage.

The system shall expose to that non-owner only the [Event Responses](../../../terminology/glossary.md#event-response) the guest is authorized to manage.
It shall not expose other responses, their availability, their identities, or their count through event payloads, [Availability Editing](../../../terminology/glossary.md#availability-editing), response selection, or [Schedule Overlap](../../../terminology/glossary.md#schedule-overlap) views.
The [Event Owner](../../../terminology/glossary.md#event-owner) shall be able to view every **Event Response**.

Blind Availability Mode shall override [Open Event Response](../../../terminology/glossary.md#open-event-response) status: a non-owner [Event Guest](../../../terminology/glossary.md#event-guest) shall not edit another guest's [Event Response](../../../terminology/glossary.md#event-response) even when it is open, as [FR-061](FR-061.md) states.
