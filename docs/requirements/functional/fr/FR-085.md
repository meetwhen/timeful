# FR-085: Exclude Scheduled-Event Cells From Availability Editing

During [Availability Editing](../../../terminology/glossary.md#availability-editing) of a [Timed Event](../../../terminology/glossary.md#timed-event) that has a [Scheduled Event Time](../../../terminology/glossary.md#scheduled-event-time), the system shall not render scheduled-event cells.

Drawing availability shall act only on regular selectable cells and shall never paint the scheduled range.

Rendering outside [Availability Editing](../../../terminology/glossary.md#availability-editing) is unchanged.
