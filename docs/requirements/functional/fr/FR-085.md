# FR-085: Exclude Timed Event Scheduled Span Cells From Availability Editing

During [Availability Editing](../../../terminology/glossary.md#availability-editing) of a [Timed Event](../../../terminology/glossary.md#timed-event) that has a [Timed Event Scheduled Span](../../../terminology/glossary.md#timed-event-scheduled-span), the system shall not render **Timed Event Scheduled Span** cells.

Drawing availability shall act only on regular selectable cells and shall never paint the [Timed Event Scheduled Span](../../../terminology/glossary.md#timed-event-scheduled-span).

Rendering outside [Availability Editing](../../../terminology/glossary.md#availability-editing) is unchanged.
