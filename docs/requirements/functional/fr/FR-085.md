# FR-085: Exclude Timed Event Occurrence Span Cells From Availability Editing

During [Availability Editing](../../../terminology/glossary.md#availability-editing) of a [Timed Event](../../../terminology/glossary.md#timed-event) that has a [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span), the system shall not render **Timed Event Occurrence Span** cells.

Drawing availability shall act only on regular selectable cells and shall never paint the [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span).

Rendering outside [Availability Editing](../../../terminology/glossary.md#availability-editing) is unchanged.
