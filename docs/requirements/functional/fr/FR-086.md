# FR-086: Render The Timed Event Occurrence Span On Timed Grids

On the [Timed Event Scheduling Page](../../../terminology/glossary.md#timed-event-scheduling-page), a [Timed Event's](../../../terminology/glossary.md#timed-event) [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span) shall render on the [Timed Grid](../../../terminology/glossary.md#timed-grid).

Selecting a range on the **Timed Grid** shall set the **Timed Event Occurrence Span** directly, without painting availability.
