# FR-086: Render the Timed Event Scheduled Span on Specific-Times Grids

On the [Timed Event Scheduling Page](../../../terminology/glossary.md#timed-event-scheduling-page), a [Timed Event's](../../../terminology/glossary.md#timed-event) [Timed Event Scheduled Span](../../../terminology/glossary.md#timed-event-scheduled-span) shall render on the specific-times [Timed Grid](../../../terminology/glossary.md#timed-grid).

Selecting specific times shall set the [Timed Event Scheduled Span](../../../terminology/glossary.md#timed-event-scheduled-span) directly, without drawing it as availability.
