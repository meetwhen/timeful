# FR-086: Render the Scheduled Event Time on Specific-Times Grids

In specific-times mode, a [Timed Event](../../../terminology/glossary.md#timed-event)'s [Scheduled Event Time](../../../terminology/glossary.md#scheduled-event-time) shall render on the specific-times [Timed Grid](../../../terminology/glossary.md#timed-grid).

Selecting specific times shall set the [Scheduled Event Time](../../../terminology/glossary.md#scheduled-event-time) directly, without drawing it as availability.
