# FR-087: Block Grid Interactions Behind the Mobile Responses Offcanvas

On mobile, while the `Responses` offcanvas is open, the system shall prevent interactions with the [Timed Grid](../../../terminology/glossary.md#timed-grid) behind it.

When the `Responses` offcanvas is closed, grid interactions work normally.
