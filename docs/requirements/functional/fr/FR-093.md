# FR-093: Clear the Slot Selection When Interacting Outside Active Grid Cells

Clicking anywhere outside active grid cells shall clear the current slot selection.

Touch taps outside active grid cells shall clear it the same way.

Covered outside areas include the gap between split sub-grids and the collapsed-hours strip.
