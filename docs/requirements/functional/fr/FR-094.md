# FR-094: Clear the Selection Immediately When Tapping a Disabled Timeslot on Mobile

On mobile, tapping a disabled timeslot shall clear the current selection immediately, with no replacement selection.

[Disabled Padding Cells](../../../terminology/glossary.md#disabled-padding-cell) are included.
