# FR-094: Clear The Selection Immediately When Tapping A Disabled Cell On Mobile

On mobile, tapping a [Timed Grid](../../../terminology/glossary.md#timed-grid) cell that shows [Disabled Status](../../../terminology/glossary.md#disabled-status) shall clear the current selection immediately, with no replacement selection.

[Padding Cells](../../../terminology/glossary.md#padding-cell) are included.
