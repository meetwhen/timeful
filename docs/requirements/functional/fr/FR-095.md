# FR-095: Keep the Grid Pointer Off Collapsed-Hours Strips

Collapsed-hours strips shall never display the [Grid Pointer](../../../terminology/glossary.md#grid-pointer), the interactive highlight marking the grid cell currently under the pointer.

The rule is state-based, so hover and touch positioning behave identically.
