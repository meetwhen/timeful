# FR-097: Include the If Needed Item in Both Response Legends

The `If needed` [Legend](../../../terminology/glossary.md#legend) item shall appear in both [Timed Event](../../../terminology/glossary.md#timed-event) and [Dates-Only Event](../../../terminology/glossary.md#dates-only-event) response presentations.
