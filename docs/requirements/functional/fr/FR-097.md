# FR-097: Include The If Needed Item In Both Legend Sections

The `If needed` [Legend Section](../../../terminology/glossary.md#legend-section) item shall appear in both [Timed Event](../../../terminology/glossary.md#timed-event) and [Dates-Only Event](../../../terminology/glossary.md#dates-only-event) response presentations.
