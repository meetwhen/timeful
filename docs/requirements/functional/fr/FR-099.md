# FR-099: Show Disabled Status When Hovering a Disabled Dates-Only Event Date

Hovering a disabled date in a [Dates-Only Event](../../../terminology/glossary.md#dates-only-event) shall show respondents a `Disabled` status, mirroring the [Timed Grid](../../../terminology/glossary.md#timed-grid) Disabled wording and treatment.
