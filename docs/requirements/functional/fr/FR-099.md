# FR-099: Show Disabled Status When Hovering a Disabled Dates-Only Event Date

Hovering a disabled date in a [Dates-Only Event](../../../terminology/glossary.md#dates-only-event) shall show respondents the [Disabled Status](../../../terminology/glossary.md#disabled-status), mirroring the [Timed Grid's](../../../terminology/glossary.md#timed-grid) disabled wording and treatment.
