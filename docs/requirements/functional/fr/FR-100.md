# FR-100: Contain the Hover Frame Inside Enabled Dates-Only Cells

Hovering an enabled cell in a dates-only grid shall draw a black inset square frame inside that cell.

The frame shall stay contained in the hovered cell without overlapping neighboring cells.

Showing the frame shall not shift the cell's date text.
