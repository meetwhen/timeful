# FR-101: Use Fixed Wording for Event-Page Availability Summaries

On the event page, an [Event Response](../../../terminology/glossary.md#event-response) summary reporting no availability shall read `Everyone is unavailable`.

An [Event Response](../../../terminology/glossary.md#event-response) summary reporting any availability shall read `Someone is available`.
