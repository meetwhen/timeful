# FR-102: Use Fixed Wording For Personal Availability On Response Editing Pages

On the response editing pages, the personal availability view shall show `You're available` for green availability and `You're not available` for red.

While the [Event Response Overlay](../../../terminology/glossary.md#event-response-overlay) is active, the view shall additionally show an overlay-colored item reading `You're available`.

Beneath that overlay item, the view shall show a plain green item reading `Someone is available`.
