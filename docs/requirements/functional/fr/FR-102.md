# FR-102: Use Fixed Wording for Personal Availability in the Availability Editor

In the [Availability Editor](../../../terminology/glossary.md#availability-editor), the personal availability view shall show `You're available` for green availability and `You're not available` for red.

While the [Availability Response Overlay](../../../terminology/glossary.md#availability-response-overlay) is active, the view shall additionally show an overlay-colored item reading `You're available`.

Beneath that overlay item, the view shall show a plain green item reading `Someone is available`.
