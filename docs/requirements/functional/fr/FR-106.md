# FR-106: Fix the Dates-Only More-Options Toggle Order

On the [Dates-Only Event Page](../../../terminology/glossary.md#dates-only-event-page), `More options` shall list `Start on Monday` above `Hide if needed days`.

This order holds across every viewport and control state.
