# FR-113: Require a Non-Empty Timed Event Scheduled Span Before Saving

Before saving, a [Timed Event's](../../../terminology/glossary.md#timed-event) [Timed Event Scheduled Span](../../../terminology/glossary.md#timed-event-scheduled-span) shall contain at least one [Timed Slot](../../../terminology/glossary.md#timed-slot).

The frontend shall block saving a [Timed Event Scheduled Span](../../../terminology/glossary.md#timed-event-scheduled-span) whose range is empty.
The backend shall reject save requests carrying an empty **Timed Event Scheduled Span**.

Clearing the [Timed Event Scheduled Span](../../../terminology/glossary.md#timed-event-scheduled-span) entirely and dates-only event scheduling are not affected.
