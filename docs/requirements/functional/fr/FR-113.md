# FR-113: Require a Non-Empty Timed Event Occurrence Span Before Saving

Before saving, a [Timed Event's](../../../terminology/glossary.md#timed-event) [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span) shall contain at least one [Time Slot](../../../terminology/glossary.md#time-slot).

The frontend shall block saving a [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span) whose range is empty.
The backend shall reject save requests carrying an empty **Timed Event Occurrence Span**.

Clearing the [Timed Event Occurrence Span](../../../terminology/glossary.md#timed-event-occurrence-span) entirely and dates-only event scheduling are not affected.
