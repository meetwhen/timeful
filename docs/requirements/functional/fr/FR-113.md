# FR-113: Require a Non-Empty Timed Range Before Saving

Before saving, a [Timed Event](../../../terminology/glossary.md#timed-event)'s timed range shall contain at least one [Timed Slot](../../../terminology/glossary.md#timed-slot).

The frontend shall block saving a [Timed Event Scheduled Span](../../../terminology/glossary.md#timed-event-scheduled-span) whose range is empty.
The backend shall reject save requests carrying an empty timed range.

Clearing the [Timed Event Scheduled Span](../../../terminology/glossary.md#timed-event-scheduled-span) entirely and dates-only event scheduling are not affected.
