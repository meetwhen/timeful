# FR-114: Switch Mobile Timed Grid Pages Between 3 And 7 Day Columns

On a mobile [Timed Event Page](../../../terminology/glossary.md#timed-event-page), the `3 days`/`7 days` range switch shall set how many day columns each [Timed Grid](../../../terminology/glossary.md#timed-grid) page displays.

The system shall show the range switch only when the [Timed Grid](../../../terminology/glossary.md#timed-grid) can display more than 3 day columns, and shall hide the switch and display every day column when the **Timed Grid** can display 3 or fewer.

[Dates-Only Event](../../../terminology/glossary.md#dates-only-event) pages shall not show the range switch.

The selected range shall persist in the visitor's browser and shall default to `3 days`.
