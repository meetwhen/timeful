# FR-118: Restrict Event-Editor Date Selection To The Current Event Timezone Date And Later

In an event-creation form's date picker, a date before the current date in the timezone selected in the form shall not be selectable.
That selected timezone becomes the [Event Timezone](../../../terminology/glossary.md#event-timezone) when the event is created.

In event editing's date picker, [Event Picked Dates](../../../terminology/glossary.md#event-picked-dates) that fall before the current date in the event's [Event Timezone](../../../terminology/glossary.md#event-timezone) shall remain selected.
In event editing's date picker, a date before that current date shall not be additionally selectable.

Changing the selected [Event Timezone](../../../terminology/glossary.md#event-timezone) in either form shall re-derive the earliest selectable date from the newly selected timezone.
