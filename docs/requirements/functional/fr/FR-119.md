# FR-119: Limit Event Names To 100 Characters

While creating or editing an event, the [Event Owner](../../../terminology/glossary.md#event-owner) shall not be able to save an event whose name is longer than 100 characters.

## Acceptance Criteria

- The new-event and edit-event forms shall prevent submitting an event name longer than 100 characters.
- The event create and update APIs shall reject an event name longer than 100 characters.
