# QR-001: Restrict Shared-Event Read Access

## Source

An actor requests an event or its responses.

## Stimulus

The actor presents a valid shared link or no valid shared link for the requested event.

## Environment

The request concerns an event and its availability data.

## Artifact

Shared-event read access.

## Response

The system shall not disclose event metadata, respondent names, or availability data without the event's valid shared link.
For a viewer with the valid shared link, the system shall disclose the event metadata, respondent names, and availability data needed to coordinate that event.

## Response Measure

Automated frontend and backend authorization tests distinguish authorized and unauthorized read requests.
