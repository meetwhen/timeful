# QR-002: Preserve Shared-Event Modification Integrity

## Source

An actor attempts a protected mutation.

## Stimulus

The actor creates, updates, deletes, or replaces event metadata or an [Availability Response](../../../terminology/glossary.md#availability-response) without the applicable creator or respondent edit credential.

## Environment

The mutation affects persisted event or response data.

## Artifact

Shared-event modification authorization.

## Response

The system shall reject the operation without changing persisted event or response data.

## Response Measure

Automated backend authorization tests confirm rejection and unchanged persisted data for every protected mutation operation.
