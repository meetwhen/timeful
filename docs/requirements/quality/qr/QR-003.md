# QR-003: Authenticate Anonymous Edit Credentials

## Source

An anonymous event creator or respondent submits a protected mutation.

## Stimulus

The request supplies an authorization credential, omits it, substitutes another credential, uses a revoked credential, or supplies only a non-authorizing identifier.

## Environment

The event uses MongoDB or PostgreSQL storage.

## Artifact

Anonymous protected-mutation authorization.

## Response

For MongoDB events, the system shall accept the mutation only when the request supplies the separately issued unpredictable [Event Response Edit Credential](../../../terminology/glossary.md#event-response-edit-credential) for that creator or response.
For PostgreSQL events, the system shall accept an anonymous [Protected Event Response](../../../terminology/glossary.md#protected-event-response) mutation only when the request proves the applicable [Event Visitor Control Credential](../../../terminology/glossary.md#event-visitor-control-credential-evcc) or [Granted Event Visitor Control Credential](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc).
An event URL, respondent name, public `eventVisitorId`, or raw [Platform Visitor Identity](../../../terminology/glossary.md#platform-visitor-identity) value shall not authorize a protected mutation.

## Response Measure

Automated tests accept the applicable credential and reject requests that omit it, substitute another credential, use a revoked [Granted Event Visitor Control Credential (Granted EVCC)](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc), or supply only a non-authorizing identifier.
