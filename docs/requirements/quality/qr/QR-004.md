# QR-004: Restrict Shared-Event Read Access

When an actor requests an event or its responses without that event's valid shared link, the system shall not disclose event metadata, respondent names, or availability data.

For a viewer with the valid shared link, the system shall disclose the event metadata, respondent names, and availability data needed to coordinate that event.
The response measure is that authorized and unauthorized read requests are distinguishable by automated frontend and backend authorization tests.
