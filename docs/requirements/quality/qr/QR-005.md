# QR-005: Preserve Shared-Event Modification Integrity

When an actor attempts to create, update, delete, or replace event metadata or
an availability response without the applicable creator or respondent edit
credential, the system shall reject the operation without changing persisted
event or response data.

The response measure is that automated backend authorization tests confirm the
rejection and unchanged persisted data for every protected mutation operation.
