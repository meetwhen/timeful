# QR-006: Respond Promptly For Timed Events

## Source

Five hundred concurrent active users view a [Timed Event](../../../terminology/glossary.md#timed-event) or save availability.

## Stimulus

Users initiate an event-view or availability-save operation.

## Environment

The representative [Timed Event](../../../terminology/glossary.md#timed-event) workload contains 500 stored responses and measures both users accessing one shared event and users distributed across Timed Events.

## Artifact

[Timed Event](../../../terminology/glossary.md#timed-event) view and availability-save operations.

## Response

The operations shall complete within two seconds at the 95th percentile.

## Response Measure

An automated performance test measures from operation initiation through the persisted save confirmation or event view.
