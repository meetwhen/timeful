# QR-006: Authenticate Anonymous Edit Credentials

For MongoDB events, when an anonymous event creator or respondent submits a protected mutation, the system shall accept it only when the request supplies the separately issued unpredictable edit token for that creator or response.

For PostgreSQL events, the system shall accept an anonymous protected-response mutation only when the request proves the applicable [Event Visitor Control Credential](../../../terminology/glossary.md#event-visitor-control-credential-evcc) or [Granted Event Visitor Control Credential](../../../terminology/glossary.md#granted-event-visitor-control-credential-granted-evcc).

An event URL, respondent name, public `eventVisitorId`, or raw [Platform Identity](../../../terminology/glossary.md#platform-identity) value shall not authorize a protected mutation.
The response measure is that automated tests accept the applicable credential and reject requests that omit it, substitute another credential, use a revoked Granted EVCC, or supply only a non-authorizing identifier.
