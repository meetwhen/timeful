# QR-006: Authenticate Anonymous Edit Credentials

When an anonymous event creator or respondent submits a protected mutation,
the system shall accept it only when the request supplies the separately issued
unpredictable edit token for that creator or response.

An event URL and respondent name shall not authorize a protected mutation. The
response measure is that automated tests accept the matching edit token and
reject requests that omit it, substitute another token, or supply only the
event URL or respondent name.
