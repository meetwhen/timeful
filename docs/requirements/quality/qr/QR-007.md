# QR-007: Exclude Secrets From Diagnostics

When the server or deployment tooling records a request, failure, startup diagnostic, or health diagnostic, it shall not include credentials, secrets, anonymous edit tokens, or URLs and headers that contain edit tokens in emitted logs or diagnostic output.

The response measure is that automated or inspected diagnostic samples covering those conditions contain none of the protected values while retaining the non-sensitive context needed to diagnose the condition.
