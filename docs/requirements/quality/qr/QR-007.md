# QR-007: Respond Promptly For Dates-Only Events

## Source

Five hundred concurrent active users view a [Dates-Only Event](../../../terminology/glossary.md#dates-only-event) or save availability.

## Stimulus

Users initiate an event-view or availability-save operation.

## Environment

The representative [Dates-Only Event](../../../terminology/glossary.md#dates-only-event) workload contains 500 stored responses and measures both users accessing one shared event and users distributed across Dates-Only Events.

## Artifact

[Dates-Only Event](../../../terminology/glossary.md#dates-only-event) view and availability-save operations.

## Response

The operations shall complete within two seconds at the 95th percentile.

## Response Measure

An automated performance test measures from operation initiation through the persisted save confirmation or event view.
