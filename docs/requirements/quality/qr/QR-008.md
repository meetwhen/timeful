# QR-008: Support Accessible Coordination Flows

## Source

A user creates an event, views an event, or submits availability.

## Stimulus

The user completes one of the supported coordination flows.

## Environment

The flow runs in a supported desktop or mobile browser.

## Artifact

Frontend coordination flows.

## Response

The frontend shall conform to WCAG 2.2 AA for those flows.

## Response Measure

Automated accessibility checks and documented manual keyboard and screen-reader checks pass for each flow before release.
Known exceptions are recorded with their affected flow and remediation status.
