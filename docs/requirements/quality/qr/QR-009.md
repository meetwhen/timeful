# QR-009: Respond Promptly For Timed Events

When 500 concurrent active users view a timed event or save availability under
the representative timed-event workload, the event-view and availability-save
operations shall complete within two seconds at the 95th percentile.

The representative workload shall contain 500 stored responses and shall be
measured both with users accessing one shared event and with users distributed
across timed events.
The response measure is an automated performance test from
operation initiation through the persisted save confirmation or event view.
