# QR-012: Reject Unsafe Deployment Configuration

When an operator starts the staging or production deployment with required
configuration missing or unsafe, the deployment shall refuse to start and
identify the configuration setting without disclosing its value.

Development and test environments are excluded where their documented isolated
configuration intentionally differs. The response measure is deployment
configuration tests that exercise every required setting and confirm that
diagnostic output contains no configured secret value.
