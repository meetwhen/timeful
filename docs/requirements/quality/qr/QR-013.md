# QR-013: Diagnose Failed Requests Without Exposing Data

## Source

A request fails.

## Stimulus

An operator investigates the failed request.

## Environment

The failure occurs in a staging or production deployment.

## Artifact

Structured log records and service health status.

## Response

An operator shall be able to correlate the failure with structured log records and service health status using a request correlation identifier or equivalent non-sensitive identifier.

## Response Measure

An operational exercise starts with a failed request and identifies the associated diagnostic records and health state without exposing values prohibited by [QR-007](QR-007.md).
