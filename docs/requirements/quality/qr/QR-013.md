# QR-013: Diagnose Failed Requests Without Exposing Data

When a request fails in a staging or production deployment, an operator shall
be able to correlate the failure with structured log records and service health
status using a request correlation identifier or equivalent non-sensitive
identifier.

The response measure is an operational exercise that starts with a failed
request and identifies the associated diagnostic records and health state
without exposing values prohibited by QR-007.
