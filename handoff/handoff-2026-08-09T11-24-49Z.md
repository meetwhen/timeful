## Findings And Risks

Benefits of the refactor (as discussed): single source of truth (enabled is a pure function of already-persisted facts), `active ⊆ enabled` holds by construction so the hand-maintained invariants in ADR-012 shrink, timezone/settings/picked-date changes become single-field writes with the domain following automatically, the server contract loses one required field and can no longer be handed an inconsistent domain, cross-surface consistency (header/grid/editor/legend) becomes structural, and one "competing authority" is removed per ADR-001/ADR-012. Costs: read-time derivation, Go must reimplement generation (parity risk), weekly anchor heuristic, and the materialized DB field is lost as a debugging artifact (mitigated by leaving stale data during rollout).

Risks, by severity:

- **R1 (High) — Go derivation vs Temporal derivation mismatch on DST transitions.** Server derive+validate is the new authority; mismatch on gap/overlap days (America/New_York spring-forward, Europe/Berlin fold, Australia/Lord_Howe 30-min) means frontend create/edit could be rejected (hard failure) or, worse, a silently divergent domain. Go `time.Date` normalization is expected to match Temporal's `compatible` disambiguation (shift forward on gap, earlier offset on fold) — must be proven by shared fixtures on both sides, not assumed.
- **R2 (High) — Silent divergence for existing events.** Everything rests on derived == previously persisted. Any legacy/edited/edge event that diverges changes grid, legend, and respondent statuses silently. Mitigations: keep stale DB field; shared cross-side fixtures in tests (Q3, resolved — no comparison script); `useCalendarGrid.test.ts` unchanged expected outputs act as the frontend parity oracle.
- **R3 (High) — Deployment ordering + pending 20260724 migration.** New frontend + old server = rejected create/edit (`errIncompleteTimedEventContract`), so the server must deploy first. Old frontend + new server is safe — `encoding/json` ignores the unknown `enabledSlots` key. The migration script's `canonicalSlots` read of `models.Event.EnabledSlots` (main.go:57-58) is fixed by decoding via a **script-local struct** independent of the model, making the script compile-safe regardless of Q2; it still writes the stale `enabledSlots` field (main.go:188) for the old-frontend window.
- **R4 (Medium) — Weekly anchor off-by-one.** Anchor = week of earliest active instant, using the messy day-index convention (Sunday = 0 and = 7, `startOnMonday` filters index 0, Temporal `dayOfWeek` is 1=Mon…7=Sun). Port the exact `daysUntil`/index logic from `eventEditorSchedule.ts:129-143` into both the frontend helper and the Go generator; test identical fixtures on both sides.
- **R5 (Medium) — Draft vs canonical shape confusion.** `SpecificTimesEditDraft` keeps a working `enabledSlots` (draft-scoped); with canonical `Event` losing the field, keep the draft field explicitly draft-scoped to avoid persisting draft domains.
- **R6 (Medium) — "True on-the-fly" churn.** 18 src test files + 11 e2e spec files + 7 e2e helpers/repro files reference `enabledSlots` (116 refs total; the "~17" estimate was low), plus many consumers. Runtime casts like `(event as { times?: … }).times` (`useCalendarGrid.ts:183`) can hide stragglers from typecheck. Exhaustive grep before/after; only `fromRawEvent` may touch raw `enabledSlots` (legacy fallbacks).
- **R8 (Medium, new) — e2e assertions break with the server change.** Each `timed-event-*` spec plus `schedule-overlap-pager-button-sizes.spec.ts`, `event-page-days-only-layout.spec.ts`, `event-description-header-layout.spec.ts`, `event-page-no-responses-layout.spec.ts`, `sign-up-form-event.spec.ts` and helpers `timed-event-helpers.ts`/`firefox-timed-event-harness.ts`/`repro/repro-*.ts` reference `enabledSlots` in fixtures/assertions; they must be updated once the server stops emitting it (Phase 4).
- **R7 (Low) — Empty-active weekly events.** No active instants ⇒ no anchor; falls back to `timeSeed` (frontend) / `time.Now()` in event tz (Go, since `timeSeed` has no server-side counterpart), which may not match what the organizer last saw. Document in the ADR amendment; accept.
